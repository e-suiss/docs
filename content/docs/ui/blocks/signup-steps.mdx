A row of progress dots, with the current step stretched into a pill, sits above a single centered question. Each step shows its number, a title that grows at `md:`, a description, and one `Input`; the password step adds a live checklist of rules. Back and Continue `Button` actions sit below, and Continue becomes Create account on the last step. Each new step slides in from the direction of travel. A success view greets the user by first name and offers a Start over link.

<Code lang="tsx" code={"<SignupSteps />"} />

Edit the `steps` array at the top of the file; each step has a `key`, `title`, `description`, `placeholder`, input `type`, `autoComplete` value, and a `valid` function. Add matching keys to the `Values` record if you add steps. The step index, the slide direction, the values, and the done flag are held in `React.useState`. Continue is enabled only when the current value is valid; replace the final transition to `done` with a call to your registration API.

## Notes

The progress list is an `ol` with `aria-label="Progress"`, the current dot has `aria-current="step"`, and each dot includes visually hidden Step text that notes completed steps. Each input is labeled with its placeholder and uses an `autoComplete` value, and inputs after the first receive focus automatically. Password rules include visually hidden (met) or (not met) text. Slide and success animations are disabled with `motion-reduce:`.
