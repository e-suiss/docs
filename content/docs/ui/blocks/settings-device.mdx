From `sm:` the screen is framed as a phone with a status bar and notch; on the smallest screens it fills the width without the frame. Inside, a scrolling column shows a Settings title, a search field built from `InputGroup`, `InputGroupAddon`, and `InputGroupInput`, an account row with `Avatar`, and inset groups of rows built from `ItemGroup`, `Item`, `ItemMedia`, `ItemContent`, `ItemTitle`, `ItemActions`, and `ItemSeparator`. Rows either link to a detail page with a caret and an optional status, or hold a `Switch`.

<Code lang="tsx" code={"import { SettingsDevice } from \"@/components/blocks/settings-device\""} />

<Code lang="tsx" code={"<SettingsDevice />"} />

Edit the `groups` array at the top of the file; each row has a `label`, an `icon`, a `tint` class, and either a `toggle` key or a `detail` function that derives its status text from the toggles. The search query and the `Toggles` record are held in `React.useState`. Turning on Airplane Mode also turns off Wi-Fi and Bluetooth, which changes their status text and hides the Wi-Fi icon in the status bar. Search filters rows by label and hides the account row while a query is entered. Row links point to hash anchors; replace them with your routes.

## Notes

The search input has `aria-label="Search settings"`. Each switch row's label is a `label` tied to its `Switch` through `htmlFor`. Rows are wrapped in `role="listitem"` elements inside the list role of `ItemGroup`. The status bar and notch are `aria-hidden`, and caret icons flip with `rtl:rotate-180`. When nothing matches, the screen shows No Results.
