Built on the `Navbar` pattern with `layout="panel"`, so items with `columns` open full-width mega-menu panels anchored to the header. The bar has a text brand link, top-level links, and two ghost icon `Button` actions. It is sticky with a translucent, blurred background that turns solid while a panel is open, and its content is centered to a 62.5rem width at `md:`. When the viewport is mobile-sized or the links do not fit, the `Navbar` pattern collapses them into a full-screen menu. A sample hero with a heading and image sits below to show the bar in context.

## Usage

<Code lang="tsx" code={"import { NavGlobal } from \"@/components/blocks/nav-global\""} />

<Code lang="tsx" code={"<NavGlobal />"} />

Edit the `items` array, typed as `NavbarItem[]`: plain entries take a `label` and `href`, and mega-menu entries take `columns`, each with a `label`, an optional `featured` flag, and a list of `links`. Replace the brand link, the hash `href` values, and the search and bag buttons, which have no handlers. The hero image URL is in the `image` constant. The block holds no state of its own.

## Notes

The search and bag buttons have `aria-label` values of Search and Shopping bag. The hero image has descriptive `alt` text and loads from Unsplash; replace it with your own. The many arbitrary `[&_[data-slot=...]]` classes restyle the `Navbar`'s navigation menu links and triggers to a compact height and hide the trigger chevrons.
