A centered form with a large heading and a single bordered field group. The email `Input` has an inline arrow submit `Button`; once a valid address is entered, a password `Input` expands below it with its own submit arrow, which shows a `Spinner` while signing in. An error line, a Remember me `Checkbox` with `Label`, and links for a forgotten password and account creation follow. On success, the form is replaced by a greeting with an `Avatar` showing the first letter of the email and a Sign out link.

The step, email, password, error message, busy flag, and signed-in flag are held in `React.useState`. The email is checked against the `EMAIL` pattern, and any password of four or more characters is accepted after a 1200 ms delay; replace the second branch of `submit` with a call to your authentication API and pass its error message to `fail`. Editing the email returns the form to the email step. Point the `#forgot` and `#create` links at your routes, and wire the Remember me checkbox, which is uncontrolled and checked by default.

## Notes

Both inputs have an `aria-label`, set `aria-invalid` for the step that failed, and reference the error line through `aria-describedby`; the error line uses `aria-live="polite"`. Inputs use `autoComplete` values of `username` and `current-password`, the collapsed password field has `tabIndex` -1, and focus moves to it once it opens. A failed submit shakes the fields with the Web Animations API unless `prefers-reduced-motion` is set. The submit arrows have `aria-label="Continue"` and flip with `rtl:rotate-180`.
