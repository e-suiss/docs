The block is wrapped in the `AppShell` pattern, which provides a sidebar of apps and reports (and a tab bar on small screens, where `AppShellTrigger` is hidden). The page header pairs the section title with a `ToggleGroup` of metrics. A card shows the current value and a Recharts `AreaChart` rendered in `ChartContainer` with `ChartTooltip`; hovering a week updates the headline value through a small `ActiveWeek` helper that reads `useActiveTooltipDataPoints`. A By region list uses `ItemGroup`, `Item`, `ItemContent`, `ItemTitle`, `ItemActions`, and `ItemSeparator`, with share bars that appear from `sm:` up.

<Code lang="tsx" code={"<DashAnalytics />"} />

Sidebar entries come from `apps` and `items` (an `AppShellItem` array grouped into Apps and Reports). Chart data lives in `metrics`, where each metric has a `value`, `label`, `unit`, and 12 weekly `data` points; `regions` lists each region's `share`. The chart color is set in `chartConfig`. The selected section, metric, and hovered week are held in `React.useState`. The sample scales each metric down for every app after the first (`1 - appIndex * 0.28`) and shows a computed growth percentage; replace both with real figures from your analytics source.

## Notes

The metric `ToggleGroup` has `aria-label="Metric"`, the headline value uses `aria-live="polite"` so it is announced as you move through the chart, and the chart enables Recharts' `accessibilityLayer` for keyboard navigation. Region rows use `role="listitem"` inside the list role of `ItemGroup`.
