A static, centered composition: a New eyebrow, a product name and tagline that grow at `md:`, two `Button` actions (a filled Learn more and an outline Buy styled with the accent color), a `2:1` product image, and a small pricing line. The text, buttons, and image fade and rise in with staggered delays using `starting:` styles. It is a server component with no state.

## Usage

```tsx
import { HeroProduct } from "@/components/blocks/hero-product"
```

```tsx
<HeroProduct />
```

Replace the copy inline and the image URL in the `image` constant at the top of the file. The buttons have no handlers; wrap them in links or add `onClick` handlers for your learn more and purchase destinations. Update the pricing footnote to match your offer.

## Notes

The image has descriptive `alt` text and loads from Unsplash; replace it with your own product photography. Entry animations are disabled with `motion-reduce:`.
