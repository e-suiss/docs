The section is a two-column grid at `md:` — the checkout steps on the left and an `aside` order summary on the right — and stacks to a single column on smaller screens. Each step is a local `Step` component that shows a numbered badge, a title, and an expanding panel that animates `grid-template-rows` when it opens. Delivery and payment choices use `RadioGroup`, `RadioGroupItem`, and `Label` rendered as selectable cards, and each step advances with a `Button`. Placing the order replaces the form with a confirmation message.

## Usage

<Code lang="tsx" code={"<BagCheckout />"} />

Replace the `items` array at the top of the file with your cart contents; each entry has a `name`, `variant`, `price`, and `image`. The `money` helper formats prices as US dollars. The component tracks the current step, the selected delivery option, the selected payment method, and whether the order was placed with `React.useState`; the total adds $19 when `shipping` is `express`. Wire the Place Order button's `onClick` to your order API instead of only setting `placed`, and replace the hard-coded order number W1049 and the delivery and payment labels.

## Notes

The open step carries `aria-current="step"`, and collapsed panels are `inert` so their controls are skipped by keyboard and assistive technologies. Completed steps show an Edit button with an `aria-label` such as Edit delivery. Each `RadioGroup` has an `aria-label`, the summary `aside` is labeled Order summary, and the total uses `aria-live="polite"` so changes are announced. Product images are decorative (`alt=""`) and load from Unsplash through the `photo` helper; replace them with your own assets. Animations are disabled with `motion-reduce:`.
