The block is wrapped in the `AppShell` pattern with an admin navigation. The header has a title with a member count, a search field built from `InputGroup`, `InputGroupAddon`, and `InputGroupInput`, and an Invite `Button`; the search and button take the full width below `sm:`. A `ToggleGroup` filters by role. The list is a `Table` (`TableHeader`, `TableRow`, `TableHead`, `TableBody`, `TableCell`) with an `Avatar`, name, and email in the first column; the Role column appears from `sm:` and the Last sign-in column from `md:`. Clicking a row selects it, and a footer shows the selection count and Make Editor, Activate, and Suspend actions.

## Usage

<Code lang="tsx" code={"import { UsersTable } from \"@/components/blocks/users-table\""} />

<Code lang="tsx" code={"<UsersTable />"} />

Replace `initialUsers` with your users (`name`, `email`, `role`, `status`, `seen`, avatar `hue`) and edit `roles` for the filter. Users, the search query, the role filter, and the selected emails are held in `React.useState`; changing the filter clears the selection. Search matches the name and email. The `bulk` function applies a patch to every selected user and then clears the selection; call your API there. The Invite button has no handler.

## Notes

Each row contains a visually hidden `Checkbox` with an `aria-label` such as Select Morgan Lee, so selection works with the keyboard as well as by clicking the row, and the row shows a focus ring while the checkbox has focus. The search input has `aria-label="Search users"`, the filter group has `aria-label="Role"`, and the selection count uses `aria-live="polite"`.
