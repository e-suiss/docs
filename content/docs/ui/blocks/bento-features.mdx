Under a Why Phone Pro heading, tiles stack in one column and become a four-column, two-row grid at `md:`. A large camera tile spans two columns and two rows, two stat tiles show a Phosphor icon (`CpuIcon`, `BatteryFullIcon`) with gradient text figures, and a wide tile spans two columns with copy beside an image. The block uses plain markup and design tokens such as `bg-surface` and `text-label-secondary`; it does not use suiss UI components or hold any state.
