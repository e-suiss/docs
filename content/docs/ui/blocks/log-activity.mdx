The block is wrapped in the `AppShell` pattern with an admin navigation (a sidebar, or a tab bar on small screens where `AppShellTrigger` is hidden). The header holds the page title, a `Select` filter (`SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`), and an Export `Button`. Events are grouped under day headings in rounded lists. Each row shows a tinted kind icon, the actor and action, the target, and a time; rows that record a change use `Collapsible`, `CollapsibleTrigger`, and `CollapsibleContent` to reveal a Before and After comparison.

## Usage

<Code lang="tsx" code={"import { LogActivity } from \"@/components/blocks/log-activity\""} />

<Code lang="tsx" code={"<LogActivity />"} />

Edit `nav` for the shell navigation, `kinds` for the event types and their icon and tint, and `events` for the log entries; each event has a `day`, `time`, `actor`, `action`, `target`, a `kind`, and an optional `diff` pair of before and after values. The filter is held in `React.useState`, and days are derived from the filtered events. The Export button has no handler; connect it and the event list to your audit log API.

## Notes

The filter's `SelectTrigger` has `aria-label="Type"`. Before and after values are marked up as a description list with `dt` and `dd`. The caret on expandable rows flips with `rtl:rotate-180`, and the expand and list animations are disabled with `motion-reduce:`.
