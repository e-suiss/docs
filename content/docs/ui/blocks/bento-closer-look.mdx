A heading sits above a rounded card that becomes a two-column grid at `md:`, with the feature list on the left and the image on the right. On smaller screens the image moves above the list using `order-1` and `order-2`. The list is built from `Accordion`, `AccordionItem`, `AccordionTrigger`, and `AccordionContent`, with the default trigger icon hidden and replaced by a plus badge that rotates when expanded. The image panel stacks one `img` per feature and fades to the active one.

## Usage

<Code lang="tsx" code={"import { BentoCloserLook } from \"@/components/blocks/bento-closer-look\""} />

<Code lang="tsx" code={"<BentoCloserLook />"} />

Edit the `features` array at the top of the file; each feature has a `title`, `description`, `image`, and `alt`. The active feature is stored with `React.useState`, and a `React.useEffect` interval advances it every 4 seconds while `auto` is true. The first time someone opens an item, `auto` is set to false and the rotation stops. Change the 4000 ms interval or the Take a closer look heading as needed.

## Notes

Images that are not active are marked `aria-hidden`, and each image has descriptive `alt` text in the data. Images load from Unsplash through the `photo` helper; replace them with your own. Transitions are disabled with `motion-reduce:`, although the automatic rotation itself still runs until the user interacts.
