Built on the `SplitView` pattern: `SplitViewList` holds the conversations as `SplitViewItem` rows, and `SplitViewDetail` shows the selected thread. Avatars use `Avatar` and `AvatarFallback` with gradient initials. The thread header has `Button` actions for video and details, the messages render in `MessageScroller` with `Message` and `Bubble`, and a local `Composer` form combines `Input` with a send `Button` that scales in once text is entered. Below `md:` the split view shows one column at a time, starting with the list (`defaultColumn="list"`), and the active row is filled with the accent color only at `md:`.

## Usage

<Code lang="tsx" code={"import { ChatConversations } from \"@/components/blocks/chat-conversations\""} />

<Code lang="tsx" code={"<ChatConversations />"} />

Replace the `threads` array at the top of the file; each thread has a `name`, a `hue` for its avatar gradient, a `time`, and `lines` written as `me:` or `them:` prefixed strings that `toLines` parses into messages. The `replies` array supplies the simulated responses. Conversations, the selected index, and the typing indicator are held in `React.useState`. The `send` function appends your message, shows the typing indicator after 500 ms, and appends a canned reply after 1800 ms; replace it with calls to your messaging backend. The New message, attachment, video call, and details buttons have no handlers.

## Notes

Icon-only buttons have `aria-label` values (New message, Video call, Details, Add attachment, Send). The message viewport is labeled Conversation with the contact name, the header status uses `aria-live="polite"` to announce typing, and the typing bubble has `aria-label="Typing"`. The composer input uses its placeholder as its `aria-label`. The detail title is visually hidden with `sr-only` but still available to assistive technologies. Message entry animations are disabled with `motion-reduce:`.
