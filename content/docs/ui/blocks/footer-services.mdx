## Usage

```tsx
import { FooterServices } from "@/components/blocks/footer-services"
```

```tsx
<FooterServices />
```

Edit `services` (icon, `title`, `description`), `sections` (directory titles and links), and `legal` at the top of the file. Links use hash anchors from the `slug` helper; replace it with your routes. The email, validation flag, and subscribed state are held in `React.useState`. On submit, the form checks the address against the `EMAIL` pattern and shows a confirmation if it matches; send the address to your mailing list provider at that point.

## Notes

The email input has `aria-label="Email address"` and sets `aria-invalid` when validation fails; the form uses `noValidate` so the custom check runs instead of the browser's. The submit button has `aria-label="Subscribe"`, and its arrow flips with `rtl:rotate-180`. The confirmation uses `role="status"`. The directory is a `nav` labeled Directory inside a `footer` landmark.
