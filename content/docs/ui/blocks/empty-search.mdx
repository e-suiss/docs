A large search field with a magnifying glass icon and a clear `Button` sits at the top of a centered column. When the query matches the start of a suggestion, a Suggested list of buttons appears. Otherwise the block shows an `Empty` composition (`EmptyHeader`, `EmptyTitle`, `EmptyDescription`, `EmptyContent`) that reads No results for the query, or an idle prompt when the field is empty, followed by secondary `Button` chips for each suggestion.

Replace the `suggestions` array at the top of the file. The query is held in `React.useState` and starts as book neo so the no-results state is visible; set it to an empty string to start idle. Matching only runs when the query begins with book and uses prefix matching; replace the `matches` computation with your search API. Selecting a suggestion sets it as the query.

## Notes

The input is a native `type="search"` field with `aria-label="Search suiss"`, and the browser's own cancel button is hidden in favor of the Clear search button, which returns focus to the input. The suggestion list is a `nav` labeled Suggested, and the empty-state header uses `aria-live="polite"`. The clear button's hit area is enlarged with an `after:` pseudo-element, and the empty state's entry animation is disabled with `motion-reduce:`.
