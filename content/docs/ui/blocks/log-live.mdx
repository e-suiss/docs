The block is wrapped in the `AppShell` pattern with an admin navigation. The header shows the title, a running or paused status, and a Pause or Resume `Button`. A three-column `dl` shows session stats, with values that grow at `md:`. The Recent events list shows up to seven entries, newest first, each with a gradient `Avatar` and `AvatarFallback` for people or a gray icon tile for system events (orange for warnings), and a pulsing Live indicator appears while streaming.

## Usage

<Code lang="tsx" code={"import { LogLive } from \"@/components/blocks/log-live\""} />

<Code lang="tsx" code={"<LogLive />"} />

Edit `nav` for the shell navigation and `feed` for the sample events; each event has an `actor`, `action`, `detail`, and either an avatar `hue` or an `icon`, plus an optional `warning` flag. Entries, the running state, and the event count are held in `React.useState`. A `React.useEffect` interval pushes the next sample event every 2200 ms while running and stamps it with the current time; replace it with a subscription to your real event stream. The Active users and Avg. response stats are hard-coded.

## Notes

The event list uses `aria-live="polite"` with `aria-relevant="additions"` so new events are announced as they arrive. Stats are marked up as a description list with `dt` and `dd`. Entry animations are disabled with `motion-reduce:`.
