The block forces the dark palette with the `dark` class and uses the `Navbar` pattern for a sticky bar with the product name as its brand, section links aligned to the end, and a small Buy `Button`. After the page scrolls past 8 pixels, the bar gains a translucent, blurred background, and the active link is marked with an underline. The sample page below has three anchored sections: an overview with a heading and hero image, a three-card highlight grid from `sm:` up, and a detail image. When space is limited, the `Navbar` pattern collapses the links into a full-screen menu.

Edit `sections` (each with an `id` and `label`), `highlights`, and the `images` URLs at the top of the file. The scrolled flag and the active section are held in `React.useState`. One `React.useEffect` listens to `window` scroll against `SCROLL_THRESHOLD`; another uses an `IntersectionObserver` with a centered root margin to find the section in view, so each `id` must match an element on the page. Give the Buy button a handler.

## Notes

The active link is passed to `Navbar` through each item's `active` flag. Both images have descriptive `alt` text and load from Unsplash; replace them with your own. The scroll listener is registered as passive.
