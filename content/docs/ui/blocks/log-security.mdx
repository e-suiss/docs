The block is wrapped in the `AppShell` pattern with an admin navigation. A summary card shows an SVG ring and a security score that drops by a weight for each open alert, changing color from green to orange to red, next to a `dl` of open alerts per severity. A `ToggleGroup` filters the list by Open, Resolved, or All. Each alert row shows a severity-tinted icon (or a check once resolved), a title and detail, and a Resolve or Reopen `Button`.

## Usage

<Code lang="tsx" code={"import { LogSecurity } from \"@/components/blocks/log-security\""} />

<Code lang="tsx" code={"<LogSecurity />"} />

Edit `initialAlerts` for the alerts (`severity`, `title`, `detail`, `icon`) and `severity` for each level's colors and score `weight`. Alerts are held in `React.useState` with an added `resolved` flag, and alerts are matched by `title` when resolving, so keep titles unique or switch to an id. The filter is also held in state. Connect Resolve and Reopen to your security backend, and replace the `nav` items with your admin routes.

## Notes

The open alert count under the title uses `aria-live="polite"`. The score ring is `aria-hidden` because the score is shown as text. The filter group has `aria-label="Filter"`, and severity counts are marked up as a description list with `dt` and `dd`.
