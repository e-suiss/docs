A centered layout with a lock icon, a heading that grows at `md:`, and an explanation above an `InputOTP` split into two `InputOTPGroup` sets of three `InputOTPSlot` cells; the slots grow slightly at `sm:`. Slot borders turn red on an error and green on success. A hint line shows the demo code or an error message. Below, a resend countdown becomes a Resend code link when it reaches zero, followed by a help link. A correct code shows a Verified confirmation with a Start over link.

<Code lang="tsx" code={"<VerifyCode />"} />

The code, the status (`idle`, `error`, or `ok`), and the seconds left are held in `React.useState`; a `React.useEffect` counts down from 30. The `complete` function compares the code to `DEMO_CODE` after 200 ms; on a mismatch it shakes the slots and clears the code after 800 ms. Replace that comparison with your verification API, remove the Demo code hint, and wire the Resend code button, which only restarts the timer, to your code delivery service. Point `#help` at your support page.

## Notes

The `InputOTP` has `aria-label="Verification code"`, receives focus on load, and references the hint through `aria-describedby`; the hint uses `aria-live="polite"` so errors are announced. The shake uses the Web Animations API and is skipped when `prefers-reduced-motion` is set, and the success animation is disabled with `motion-reduce:`.
