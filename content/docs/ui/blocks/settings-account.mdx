The block uses the `AppShell` pattern with `collapsible="offcanvas"`, a profile header with a large `Avatar`, name, and email, and seven account sections. Only Sign-In and Security is implemented: it shows two local `EditableCard` components that expand into an `Input` with Save and Cancel `Button` actions, a Passkeys row with a `Switch`, a read-only two-factor row, and a status line confirming each save. Other sections show a placeholder message. The content column is centered with a maximum width, and its padding grows at `md:`.

## Usage

<Code lang="tsx" code={"import { SettingsAccount } from \"@/components/blocks/settings-account\""} />

<Code lang="tsx" code={"<SettingsAccount />"} />

Edit `items` for the sidebar sections. The selected section is held in `React.useState` and starts at `security`. Inside the local `Security` component, the email and phone values, the card being edited, the passkey switch, and the saved message are held in `React.useState`; the message clears after 2200 ms. Replace the `onSave` handler with a call to your account API, load the initial values from the signed-in user, and add content for the other sections. The profile name, email, and initials in the header are hard-coded.

## Notes

Each Edit button has an `aria-label` such as Edit email and phone, and collapsed edit forms are `inert`. When a card opens, focus moves to its `Input`, which is labeled with the card title. The Passkeys `Switch` is labeled by a `label` through `htmlFor`. Save confirmations are announced through `role="status"`. The edit and section transitions are disabled with `motion-reduce:`.
