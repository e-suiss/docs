The section forces the dark palette with the `dark` class. Tiles stack in one column and become a three-column, two-row grid at `md:`: a background-image tile spans both rows, two tiles show large gradient figures (8x and 4K 120), and a charging tile spans two columns. ## Usage

```tsx
import { BentoStats } from "@/components/blocks/bento-stats"
```

```tsx
<BentoStats />
```

Copy and figures are inline in the JSX. The background photo comes from the `image` constant at the top of the file. The progress value is kept in `React.useState` and set from 0 to 50 by a `React.useEffect` timeout after 400 ms so the bar animates in; change the target value to match your claim.

## Notes

The `Progress` bar has an `aria-label` of Charge after 20 minutes. The photo tile is a CSS `backgroundImage`, so it has no text alternative; the tile's heading carries the meaning. The image loads from Unsplash; replace it with your own. The progress transition is disabled with `motion-reduce:`.
