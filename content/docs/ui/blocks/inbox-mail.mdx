Built on the `SplitView` pattern with `SplitViewSidebar` for mailboxes, `SplitViewList` for messages, and `SplitViewDetail` for the reader; each row is a `SplitViewItem`. The list header shows the mailbox name, an unread count, and a New message `Button`, followed by a search field built from `InputGroup`, `InputGroupAddon`, and `InputGroupInput`. The local `Reader` component shows a toolbar of ghost icon `Button` actions, a sender `Avatar`, the message, and a reply form with `Textarea`. Below `md:` the split view shows one column at a time, starting with the list.

## Usage

<Code lang="tsx" code={"<InboxMail />"} />

Replace `initialMail` with your messages (`id`, `from`, `subject`, `body`, `time`, avatar `hue`, `unread`, `starred`) and `mailboxes` with your folders. The mail, mailbox, selected message, and search query are held in `React.useState`. Search matches the sender, subject, and body. Only the Starred mailbox filters the list; Inbox, Sent, Archive, and Trash all show every message, so load each folder from your mail backend. Archive and Delete both remove the message, the reply form only clears on submit, and the New message button has no handler.

## Notes

The search input has `aria-label="Search mail"`, and the New message and toolbar buttons are labeled; the Star button exposes `aria-pressed`. Unread dots include visually hidden Unread text, the row star icon has `aria-label="Starred"`, and the reply `Textarea` is labeled with the sender's name and receives focus when it opens. The detail title is visually hidden with `sr-only`. Entry animations are disabled with `motion-reduce:`.
