Uses `LineChart` with two `Line` elements, `desktop` and `mobile`, both `type="monotone"` with `strokeWidth={2.5}` and `dot={false}`. `chartData` holds six months of `{ month, desktop, mobile }` records; `chartConfig` colors `desktop` with `var(--blue)` and `mobile` with `var(--teal)`. `ChartLegend` renders `ChartLegendContent`, and the tooltip uses the default `ChartTooltipContent` with a label and dot indicators.

## Usage

```tsx
import { LineChartMultiple } from "@/components/charts/line-chart-multiple"
```

```tsx
<LineChartMultiple />
```

Replace `chartData` with one numeric key per series. To add a line, add a `chartConfig` entry with `label` and `color` and a `Line` with `stroke="var(--color-<key>)"`; the legend and tooltip pick it up from `chartConfig`.

## Notes

`accessibilityLayer` is set on `LineChart`, so the plot is focusable and arrow keys move the tooltip between points.
