Uses `RadialBarChart` with `innerRadius="72%"`, `startAngle={90}`, `endAngle={-270}` and `barSize={16}`, and one `RadialBar` with `cornerRadius={20}` and a background tinted to 22% of its color with `color-mix`. `chartData` holds a single `{ name, value, fill }` record with `value` 72 and `fill` set to `var(--color-value)`; `chartConfig.value` uses `var(--blue)`. A `PolarAngleAxis` with `type="number"` and `domain={[0, 100]}` (ticks and axis line hidden) makes the bar's length a percentage of the full arc rather than of the largest value. The centered text is an absolutely positioned overlay.

Set `value` in `chartData` to your percentage and change the `chartConfig.value` color as needed. The overlay text is static, so update the 72% and the caption to match your data, or render them from `chartData`. For values outside 0 to 100, change the `PolarAngleAxis` `domain`.

## Notes

There is no tooltip; the center text carries the value. `accessibilityLayer` is set on `RadialBarChart`, so the chart is focusable from the keyboard.
