Uses `RadarChart` with `outerRadius="74%"`, a `PolarGrid`, a `PolarAngleAxis` with a custom `tick` that bolds the hovered axis, and a hidden `PolarRadiusAxis` fixed to `domain={[0, 100]}`. One `Radar` is rendered per visible model from `MODELS`, with `isAnimationActive={false}`. `SCORES` holds six scores per model for the axes in `AXES`; `data` multiplies each score by an animated `scale` from `useMorph` so shapes grow from the center, and also stores the raw value as `<model>Score`. `chartConfig` defines `pro` (`var(--orange)`), `standard` (`var(--blue)`), `air` (`var(--cyan)`) and `lite` (`var(--purple)`). `React.useState` holds the selected models and the hovered axis, which an `ActiveAxis` child reads with `useActiveTooltipLabel`.

Replace `AXES` and `SCORES` with your own dimensions and items, and add a `chartConfig` entry for each item; extend the `Model` type to match. Change `MAX_SELECTED` to allow more simultaneous items and `GROW_DURATION` to adjust the animation. The tooltip filters its payload to selected models and its `formatter` shows the raw `<model>Score`, not the animated value.

## Notes

Selecting beyond `MAX_SELECTED` drops the oldest selection, and the last selected model can't be turned off. The chips are `Toggle` buttons in a `role="group"` labeled Models, and the score list is an `aria-live="polite"` region showing either the overall average or the hovered axis score. `useMorph` skips the animation under `prefers-reduced-motion: reduce`. `accessibilityLayer` is set on `RadarChart`, so the chart is focusable and arrow keys move between axes.
