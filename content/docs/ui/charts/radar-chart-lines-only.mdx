Uses `RadarChart` with `outerRadius="70%"`, a `PolarAngleAxis` on `skill`, a `PolarGrid` stroked with `var(--separator)`, and two `Radar` series (`lastMonth`, then `thisMonth`) with `fillOpacity={0}` and `strokeWidth={2.5}`. `chartData` holds six `{ skill, thisMonth, lastMonth }` records. `chartConfig` colors `thisMonth` with `var(--green)` and `lastMonth` with `var(--gray)`. The tooltip uses `ChartTooltipContent` with `indicator="line"` and `cursor={false}`.

Replace `chartData` with one record per axis, keeping a category key for `PolarAngleAxis dataKey` and a numeric key per series. Rename series in `chartConfig` and in the `var(--color-<key>)` references on each `Radar`. Use this variant when several series overlap heavily and fills would obscure each other.

## Notes

`accessibilityLayer` is set on `RadarChart`, so the chart is focusable and arrow keys move between axes.
