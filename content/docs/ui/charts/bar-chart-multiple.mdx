Uses `BarChart` with `barGap={3}` and two `Bar` elements, `desktop` and `mobile`, each with `radius={4}`. `chartData` holds six months of `{ month, desktop, mobile }` records; `chartConfig` colors `desktop` with `var(--blue)` and `mobile` with `var(--teal)`. The grid and an `XAxis` on `month` whose `tickFormatter` shortens labels to three letters match the default bar chart, and the tooltip uses `indicator="dashed"` with `cursor={false}`.

## Usage

<Code lang="tsx" code={"<BarChartMultiple />"} />

Replace `chartData` with one numeric field per series. To add a series, add a `chartConfig` entry with `label` and `color` and another `Bar` with `fill="var(--color-<key>)"`. Change `barGap` to control the space between bars within a group.

## Notes

`accessibilityLayer` is set on `BarChart`, so the plot is focusable and arrow keys move between bars.
