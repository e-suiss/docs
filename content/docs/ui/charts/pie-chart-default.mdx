Uses `PieChart` with one `Pie` (`dataKey="users"`, `nameKey="device"`, `outerRadius="85%"`) and a 2-pixel `stroke` of `var(--surface-secondary)` between slices. `chartData` holds five `{ device, users, fill }` records, where each `fill` is `var(--color-<device>)`. `chartConfig` defines `users` (label only) plus `phone`, `laptop`, `tablet`, `watch` and `other` colored `var(--blue)`, `var(--teal)`, `var(--indigo)`, `var(--orange)` and `var(--gray)`. The tooltip uses `ChartTooltipContent` with `hideLabel` and `nameKey="device"`.

Replace `chartData` with your categories, giving each record a `fill` of `var(--color-<key>)`, and add a matching `chartConfig` entry with `label` and `color` for every key. Keep `dataKey` and `nameKey` on `Pie` pointed at your value and category fields, and update the tooltip's `nameKey` if you rename the category field. Adjust `outerRadius` to change the pie's size within the container.

## Notes

Slice colors come from each record's `fill`, which resolves through the `--color-<key>` properties that `ChartContainer` generates from `chartConfig`. `accessibilityLayer` is set on `PieChart`, so the chart is focusable and arrow keys move between slices.
