Uses `BarChart` with `layout="vertical"`, a category `YAxis` on `device` and a hidden numeric `XAxis`. `chartData` holds `{ device, users, fill }` records where each `fill` points at `var(--color-<device>)`, so the single `Bar` (`dataKey="users"`, `radius={5}`, `barSize={18}`) picks up a per-row color. `chartConfig` defines `users` (label only) and `phone`, `laptop`, `tablet`, `watch` and `other` with `var(--blue)`, `var(--teal)`, `var(--indigo)`, `var(--orange)` and `var(--gray)`. The `YAxis` `tickFormatter` shows each device's `label` from `chartConfig`.

<Code lang="tsx" code={"<BarChartHorizontal />"} />

Replace `chartData` with your categories, giving each a `fill` of `var(--color-<key>)`, and add a matching `chartConfig` entry with `label` and `color` for every key. The tooltip uses `nameKey="device"`, so it resolves names from the `device` field; update it if you rename that field. Change `barSize` to set bar thickness.

## Notes

`YAxis` uses `width="auto"` so long category names get the space they need. `accessibilityLayer` is set on `BarChart`, so the plot is focusable and arrow keys move between bars.
