Uses `AreaChart` with `stackOffset="expand"` and two `Area` series (`mobile`, then `desktop`) sharing `stackId="a"`, `type="natural"` at `fillOpacity={0.35}`. `chartData` holds six months of `{ month, desktop, mobile }` records; `chartConfig` colors `desktop` with `var(--blue)` and `mobile` with `var(--teal)`. A right-aligned `YAxis` shows `ticks={[0, 0.5, 1]}` formatted as percentages with `tickFormatter`.

## Usage

```tsx
import { AreaChartStackedExpand } from "@/components/charts/area-chart-stacked-expand"
```

```tsx
<AreaChartStackedExpand />
```

Replace `chartData` with raw values; `stackOffset="expand"` converts them to proportions for you. Add series by adding a `chartConfig` entry and an `Area` with the same `stackId`. Keep the `YAxis` `tickFormatter` that multiplies by 100, because the expanded domain runs from 0 to 1.

## Notes

The tooltip still reports the original values from `chartData`, not the percentages. `accessibilityLayer` is set on the chart, so the plot is focusable and arrow keys move the tooltip between months.
