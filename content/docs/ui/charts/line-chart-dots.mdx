Uses `LineChart` with one `Line` (`type="linear"`, `strokeWidth={2}`) whose `dot` draws a 3.5-pixel marker and whose `activeDot` grows to 5 pixels. `chartData` is mapped from ten weights into `{ month, weight }` records, with `month` produced by `Intl.DateTimeFormat`. `chartConfig.weight` uses `var(--purple)`. A right-hand `YAxis` uses `domain={[76, 84]}` and `ticks={[76, 80, 84]}`, and the `XAxis` labels every third month via `interval={2}`.

Replace the weight array with your readings and set the `YAxis` `domain` and `ticks` to bracket your range. The tooltip uses `hideIndicator` and a `formatter` that appends `kg`; change the unit there. The header value and summary line are static text, so update them alongside the data.

## Notes

The header uses plain paragraphs rather than `CardTitle`. `accessibilityLayer` is set on `LineChart`, so the plot is focusable and arrow keys move the tooltip between points.
