## Usage

```tsx
import { RadialChartDefault } from "@/components/charts/radial-chart-default"
```

```tsx
<RadialChartDefault />
```

Replace `chartData` with your categories, giving each a `fill` of `var(--color-<key>)`, and add a matching `chartConfig` entry with `label` and `color`. Update the tooltip's `nameKey` if you rename the `device` field. Without a `PolarAngleAxis`, bar lengths are scaled relative to the largest value; add one with a numeric `domain` if you need a fixed scale.

## Notes

`accessibilityLayer` is set on `RadialBarChart`, so the chart is focusable from the keyboard.
