Stacks two `ChartContainer` elements in the same box, both rendering `RadialBarChart` with the shared `shape` props (`innerRadius="25%"`, `outerRadius="100%"`, `barSize={12}`) and a `PolarAngleAxis` with `domain={[0, MAX]}`. The back chart draws `tracks`, a copy of `chartData` with every value set to `MAX` and each `fill` mixed to 22% with `color-mix`. The front chart draws `chartData` on top and carries the tooltip. `chartData` holds four `{ device, users, fill }` records, where each `fill` is `var(--color-<device>)`, and `chartConfig` defines `users` (label only) plus `phone`, `laptop`, `tablet` and `watch` colored `var(--blue)`, `var(--teal)`, `var(--indigo)` and `var(--orange)`.

## Usage

<Code lang="tsx" code={"import { RadialChartTinted } from \"@/components/charts/radial-chart-tinted\""} />

<Code lang="tsx" code={"<RadialChartTinted />"} />

Replace `chartData` with your categories, giving each a `fill` of `var(--color-<key>)`, and add a matching `chartConfig` entry with `label` and `color`. Update the tooltip's `nameKey` if you rename the `device` field. Set `MAX` to the value that should fill a full circle; `tracks` is derived from `chartData` automatically. Change the 22% in the `color-mix` expression to make the tint stronger or lighter.

## Notes

The track chart is `aria-hidden` with `accessibilityLayer={false}` and no animation, so only the front chart is exposed to assistive technology. `accessibilityLayer` is set on the front `RadialBarChart`, so the chart is focusable from the keyboard.
