Uses a `BarChart` with two `Bar` elements, `desktop` and `mobile`, stacked with `stackId="a"` (`maxBarSize={30}`, outer corners rounded), and an `XAxis` on `month` abbreviated to three letters. `chartData` holds six months of `{ month, desktop, mobile }` records, and `chartConfig` colors `desktop` with `var(--blue)` and `mobile` with `var(--teal)`. The tooltip is `ChartTooltipContent` with `hideIndicator`, which keeps the month label but drops the color swatch beside each row. `ChartTooltip` sets `defaultIndex={2}` so the tooltip is visible on load, and `cursor={false}`; the chart's top `margin` of 70 leaves room for it above the bars.

Replace `chartData` and `chartConfig` with your own series; the tooltip reads each row's label and color from `chartConfig`. Remove `defaultIndex` if the tooltip should appear only on hover or focus. Use `hideIndicator` when there is only one series or when names alone identify each row.

## Notes

Without indicators, readers rely on the series labels from `chartConfig`, so keep them descriptive. `accessibilityLayer` is set on the chart, so the plot is focusable and arrow keys move the tooltip between categories.
