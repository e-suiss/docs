Uses `LineChart` with one `Line` per visible city (`type="monotone"`, `dot={false}`), a right-hand `YAxis` fixed to `domain={[-20, 40]}` with `allowDataOverflow`, and a `ReferenceLine` at zero. `chartConfig` defines `istanbul`, `ankara`, `izmir`, `antalya` and `erzurum` with `var(--blue)`, `var(--purple)`, `var(--teal)`, `var(--orange)` and `var(--indigo)`. `data` is built with `React.useMemo` from `CITIES` into twelve `{ index, month, ...cities }` records using `temperature()`, which derives highs and lows from each city's `spread`. `React.useState` holds the visible cities, the `mode` chosen in a `ToggleGroup`, and the hovered month reported by an `ActiveMonth` child via `useActiveTooltipDataPoints`. A summary grid below the chart shows each city's range, or its value for the hovered month.

Replace `CITIES` with your own series, each with twelve monthly `average` values and a `spread`, and add a matching `chartConfig` entry; extend the `City` type accordingly. If you have real highs and lows, return them from `temperature()` instead of the derived values. Adjust the `YAxis` `domain` and `ticks` for your range. The tooltip's `labelFormatter` shows the full month name and its `formatter` draws a swatch, label and value with a degree sign.

## Notes

`toggle` never hides the last visible city, so the chart is never empty. Each city chip is a `Toggle` inside a `role="group"` labeled Cities, and the mode switch has `aria-label="Temperature"`. New lines draw in with a `stroke-dashoffset` transition that is turned off under `motion-reduce`. `accessibilityLayer` is set on `LineChart`, so the plot is focusable and arrow keys move the tooltip between months.
