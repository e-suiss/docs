Uses `AreaChart` with two `Area` series sharing `stackId="a"`: `mobile` forms the base layer and `desktop` stacks on top, both `type="natural"` at `fillOpacity={0.2}`. `chartData` holds six months of `{ month, desktop, mobile }` records; `chartConfig` colors `desktop` with `var(--blue)` and `mobile` with `var(--teal)`. `ChartLegend` with `ChartLegendContent` labels both series, and the tooltip uses `indicator="dot"`.

Replace `chartData` keeping one category key and one numeric key per series. To add a layer, add a `chartConfig` entry with `label` and `color`, then an `Area` with the same `stackId`. Series are stacked in the order the `Area` elements appear, so list the base layer first.

## Notes

The legend reads labels and colors from `chartConfig`. `accessibilityLayer` is set on the chart, so the plot is focusable and arrow keys move the tooltip between months.
