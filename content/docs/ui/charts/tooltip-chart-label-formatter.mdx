Uses `AreaChart` with one `Area` (`type="monotone"`) filled by a vertical `linearGradient` whose `id` comes from `React.useId()`. `chartData` holds fourteen `{ date, energy }` records with `YYYY-MM-DD` dates; the `XAxis` shows the day number for every third point (`interval={2}`). `chartConfig.energy` uses `var(--red)`. The tooltip is `ChartTooltipContent` with `indicator="line"` and a `labelFormatter` that formats the hovered record's `date` with `Intl.DateTimeFormat` (`weekday`, `month` and `day` in long form). `ChartTooltip` sets `defaultIndex={8}`.

Replace `chartData` with your dated records, keeping ISO date strings so both the axis and `labelFormatter` can parse them. Change the options passed to `Intl.DateTimeFormat` in `longDate` to adjust the heading format. Remove `defaultIndex` if the tooltip should appear only on interaction.

## Notes

`labelFormatter` reads the date from `payload[0].payload` rather than its first argument, so it works regardless of what the axis displays. `accessibilityLayer` is set on the chart, so the plot is focusable and arrow keys move the tooltip between categories.
