## Usage

```tsx
import { PieChartDonut } from "@/components/charts/pie-chart-donut"
```

```tsx
<PieChartDonut />
```

Replace `chartData` with your categories, giving each record a `fill` of `var(--color-<key>)`, and add a matching `chartConfig` entry with `label` and `color` for every key. Keep `dataKey` and `nameKey` on `Pie` pointed at your value and category fields, and update the tooltip's `nameKey` if you rename the category field. Change `innerRadius` to make the ring thinner or thicker, and `paddingAngle` to widen the gaps.

## Notes

`accessibilityLayer` is set on `PieChart`, so the chart is focusable and arrow keys move between slices.
