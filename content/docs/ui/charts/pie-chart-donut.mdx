Uses `PieChart` with one `Pie` set to `innerRadius="58%"` and `outerRadius="85%"`, `paddingAngle={1}` and `strokeWidth={0}`. `chartData` holds five `{ device, users, fill }` records, where each `fill` is `var(--color-<device>)`. `chartConfig` defines `users` (label only) plus `phone`, `laptop`, `tablet`, `watch` and `other` colored `var(--blue)`, `var(--teal)`, `var(--indigo)`, `var(--orange)` and `var(--gray)`. The tooltip uses `ChartTooltipContent` with `hideLabel` and `nameKey="device"`.

## Usage

<Code lang="tsx" code={"import { PieChartDonut } from \"@/components/charts/pie-chart-donut\""} />

<Code lang="tsx" code={"<PieChartDonut />"} />

Replace `chartData` with your categories, giving each record a `fill` of `var(--color-<key>)`, and add a matching `chartConfig` entry with `label` and `color` for every key. Keep `dataKey` and `nameKey` on `Pie` pointed at your value and category fields, and update the tooltip's `nameKey` if you rename the category field. Change `innerRadius` to make the ring thinner or thicker, and `paddingAngle` to widen the gaps.

## Notes

`accessibilityLayer` is set on `PieChart`, so the chart is focusable and arrow keys move between slices.
