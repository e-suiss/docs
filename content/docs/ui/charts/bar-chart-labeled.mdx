]

const chartConfig = {
  desktop: { label: "Desktop", color: "var(--blue)" },
} satisfies ChartConfig

export function BarChartLabeled() {
  return (

      <CardHeader>
        <CardTitle>Labeled</CardTitle>
        <CardDescription>The value sits above each bar</CardDescription>
      </CardHeader>
      <CardContent>
        <ChartContainer
          config={chartConfig}
          className="aspect-auto h-48 w-full"
        >
          <BarChart
            accessibilityLayer
            data={chartData}
            margin={{ top: 22, right: 4, left: 4, bottom: 0 }}
          >
            <XAxis
              dataKey="month"
              tickLine={false}

            />
            <ChartTooltip

              dataKey="desktop"
              fill="var(--color-desktop)"
              radius={6}
              maxBarSize={36}

              />
            </Bar>
          </BarChart>
        </ChartContainer>
      </CardContent>
    </Card>
  )
}

</Example>

Uses `BarChart` with one `Bar` (`radius={6}`, `maxBarSize={36}`) containing a `LabelList` with `position="top"`, `offset={8}` and `fontSize={12}`. There is no `CartesianGrid`, and the top margin is raised to 22 to leave room for the labels. `chartData` holds six months of `{ month, desktop, mobile }` records; only `desktop` is plotted with `chartConfig.desktop` (`var(--blue)`). The tooltip uses `hideLabel` and `cursor={false}`.

## Usage

```tsx
import { BarChartLabeled } from "@/components/charts/bar-chart-labeled"
```

```tsx
<BarChartLabeled />
```

Replace `chartData` keeping the category and value keys, and rename the `chartConfig` entry to match. Change `LabelList` `position` (for example `"inside"` or `"insideTop"`) to move labels, and pass a `formatter` to `LabelList` if values need units. Increase the top `margin` if larger labels are clipped.

## Notes

Labels are styled with the `fill-label` class so they follow the label color token in light and dark appearance. `accessibilityLayer` is set on `BarChart`, so the plot is focusable and arrow keys move between bars.
