Uses `RadarChart` with `outerRadius="70%"`, a `PolarAngleAxis` on `skill`, a `PolarGrid` with `gridType="circle"` stroked with `var(--separator)`, and one `Radar` for `thisMonth` at `fillOpacity={0.3}`. `chartData` holds six `{ skill, thisMonth, lastMonth }` records. `chartConfig` colors `thisMonth` with `var(--green)` and `lastMonth` with `var(--gray)`. The tooltip uses `ChartTooltipContent` with `indicator="line"` and `cursor={false}`.

## Notes

`accessibilityLayer` is set on `RadarChart`, so the chart is focusable and arrow keys move between axes.
