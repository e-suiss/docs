Uses `BarChart` with three `Bar` elements (`services`, `laptops`, `phones`) stacked with `stackId="a"`, a dashed `CartesianGrid`, an `XAxis` on `quarter`, a right-hand `YAxis` with a `B` suffix, and a `ChartLegend`. `chartData` is mapped from tuples into eight `{ quarter, phones, laptops, services }` records, and `chartConfig` colors them `var(--blue)`, `var(--teal)` and `var(--purple)`. `React.useState` drives the `ChartTooltipContent` props: `indicator` and the tooltip `trigger` come from two `ToggleGroup` controls, while `hideLabel`, `hideIndicator` and whether a `labelFormatter` adds the summed total come from `Switch` controls. `ChartTooltip` is keyed on `trigger` so it remounts when the trigger changes, and opens at `defaultIndex={4}`.

Use this variant to try combinations, then copy the chosen props onto `ChartTooltipContent` in your chart. The total `labelFormatter` sums `payload` values and formats them with `Intl.NumberFormat`; reuse it for any stacked chart. Set `trigger="click"` on `ChartTooltip` to show the tooltip only when a bar is clicked.

## Notes

Each `Switch` is paired with a `label` through an id from `React.useId()`, and both `ToggleGroup` controls have an `aria-label`. `accessibilityLayer` is set on the chart, so the plot is focusable and arrow keys move the tooltip between categories.
