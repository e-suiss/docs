Uses `PieChart` with one `Pie` at `outerRadius="68%"` to leave room for labels, a 2-pixel `var(--surface-secondary)` stroke, `labelLine` stroked with `var(--separator-strong)`, and a `label` render function that returns a `text` element anchored to `start` or `end` depending on which side of the center it falls. The label text is the slice's `label` from `chartConfig`. `chartData` holds five `{ device, users, fill }` records, where each `fill` is `var(--color-<device>)`. `chartConfig` defines `users` (label only) plus `phone`, `laptop`, `tablet`, `watch` and `other` colored `var(--blue)`, `var(--teal)`, `var(--indigo)`, `var(--orange)` and `var(--gray)`. The tooltip uses `ChartTooltipContent` with `hideLabel` and `nameKey="device"`.

## Usage

<Code lang="tsx" code={"<PieChartLabel />"} />

Replace `chartData` with your categories, giving each record a `fill` of `var(--color-<key>)`, and add a matching `chartConfig` entry with `label` and `color` for every key. Keep `dataKey` and `nameKey` on `Pie` pointed at your value and category fields, and update the tooltip's `nameKey` if you rename the category field. Labels read from `chartConfig`, so set the `label` you want displayed there. Return a value or percentage from the `label` function instead if you prefer numbers, and lower `outerRadius` if long labels are clipped.

## Notes

Label text uses the `fill-label` class so it follows the label color in light and dark appearance. `accessibilityLayer` is set on `PieChart`, so the chart is focusable and arrow keys move between slices.
