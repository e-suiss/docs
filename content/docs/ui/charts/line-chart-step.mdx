Uses `LineChart` with one `Line` set to `type="step"` (`strokeWidth={2.5}`, `dot={false}`), a dashed horizontal `CartesianGrid` and an `XAxis` on `month` abbreviated to three letters. `chartData` holds six months of `{ month, desktop, mobile }` records; only `desktop` is plotted with `chartConfig.desktop` (`var(--blue)`). The tooltip uses `hideLabel`.

## Usage

```tsx
import { LineChartStep } from "@/components/charts/line-chart-step"
```

```tsx
<LineChartStep />
```

Use this variant for values that change in discrete jumps. Replace `chartData` and rename the `chartConfig` entry as needed. Recharts also accepts `"stepBefore"` and `"stepAfter"` for `type` to move where each step occurs.

## Notes

`accessibilityLayer` is set on `LineChart`, so the plot is focusable and arrow keys move the tooltip between points.
