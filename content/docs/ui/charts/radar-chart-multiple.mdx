Uses `RadarChart` with `outerRadius="70%"`, a `PolarAngleAxis` on `skill`, a `PolarGrid` stroked with `var(--separator)`, and two `Radar` series, `lastMonth` drawn first and `thisMonth` on top, each at `fillOpacity={0.18}` with `strokeWidth={2}`. `chartData` holds six `{ skill, thisMonth, lastMonth }` records. `chartConfig` colors `thisMonth` with `var(--green)` and `lastMonth` with `var(--gray)`. The tooltip uses `ChartTooltipContent` with `indicator="line"` and `cursor={false}`.

## Usage

<Code lang="tsx" code={"<RadarChartMultiple />"} />

Replace `chartData` with one record per axis, keeping a category key for `PolarAngleAxis dataKey` and a numeric key per series. Rename series in `chartConfig` and in the `var(--color-<key>)` references on each `Radar`. To add a series, add a `chartConfig` entry with `label` and `color` and another `Radar`; keep the fill opacity low so overlapping shapes stay readable.

## Notes

`accessibilityLayer` is set on `RadarChart`, so the chart is focusable and arrow keys move between axes.
