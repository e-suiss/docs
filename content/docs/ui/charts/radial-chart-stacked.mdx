```tsx title="components/charts/radial-chart-stacked.tsx"
  Card,

const chartData = [visitors]

const chartConfig = {

const total = visitors.desktop + visitors.mobile

export function RadialChartStacked() {

          <ChartContainer

            <RadialBarChart

              startAngle={180}
              endAngle={0}
              innerRadius="120%"
              outerRadius="170%"
              cy="86%"

              <PolarAngleAxis
                type="number"

                content={<ChartTooltipContent hideLabel />}

                dataKey="desktop"
                stackId="a"

                fill="var(--color-desktop)"
                stroke="var(--surface-secondary)"
                strokeWidth={3}
              />

                dataKey="mobile"
                stackId="a"
                cornerRadius={6}
                fill="var(--color-mobile)"
                stroke="var(--surface-secondary)"

              />
            </RadialBarChart>
          </ChartContainer>
          <div className="pointer-events-none absolute inset-x-0 bottom-[14%] flex flex-col items-center text-center">
            <span className="text-2xl font-semibold tracking-tight tabular-nums">
              {total.toLocaleString("en-US")}
            </span>
            <span className="text-xs text-label-secondary">visitors</span>
          </div>
        </div>
      </CardContent>
    </Card>
  )
}
```

</Example>

Uses `RadialBarChart` with `startAngle={180}`, `endAngle={0}`, `innerRadius="120%"`, `outerRadius="170%"` and `cy="86%"`, and two `RadialBar` elements (`desktop`, `mobile`) sharing `stackId="a"`, each with `cornerRadius={6}` and a 3-pixel `var(--surface-secondary)` stroke. `chartData` is a single `visitors` record `{ desktop, mobile }`; `chartConfig` colors `desktop` with `var(--blue)` and `mobile` with `var(--teal)`. A `PolarAngleAxis` with `domain={[0, total]}` makes the two segments fill the arc exactly. The overlay shows `total`.

## Usage

```tsx
import { RadialChartStacked } from "@/components/charts/radial-chart-stacked"
```

```tsx
<RadialChartStacked />
```

Replace `visitors` with your own fields and add a `RadialBar` with the same `stackId` and a `chartConfig` entry for each one; include every field in `total` so the arc stays full. Adjust `cy` and the radii together if you change the container height.

## Notes

The tooltip uses `hideLabel`. `accessibilityLayer` is set on `RadialBarChart`, so the chart is focusable from the keyboard.
