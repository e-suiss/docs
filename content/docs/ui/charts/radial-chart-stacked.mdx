Uses `RadialBarChart` with `startAngle={180}`, `endAngle={0}`, `innerRadius="120%"`, `outerRadius="170%"` and `cy="86%"`, and two `RadialBar` elements (`desktop`, `mobile`) sharing `stackId="a"`, each with `cornerRadius={6}` and a 3-pixel `var(--surface-secondary)` stroke. `chartData` is a single `visitors` record `{ desktop, mobile }`; `chartConfig` colors `desktop` with `var(--blue)` and `mobile` with `var(--teal)`. A `PolarAngleAxis` with `domain={[0, total]}` makes the two segments fill the arc exactly. The overlay shows `total`.

## Notes
