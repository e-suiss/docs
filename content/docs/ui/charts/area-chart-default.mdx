Built with `AreaChart` and one `Area` using `type="natural"`, a horizontal dashed `CartesianGrid` (`vertical={false}`, `strokeDasharray="2 4"`) and an `XAxis` keyed on `month` whose `tickFormatter` shortens labels to three letters. `chartData` holds six months of `{ month, desktop, mobile }` records; only `desktop` is plotted, colored by `chartConfig.desktop` (`var(--blue)`). The area uses a flat fill at `fillOpacity={0.18}`, and `ChartTooltipContent` uses `indicator="line"`.

Replace `chartData` with your own records, keeping a category field for `XAxis dataKey` and a numeric field for `Area dataKey`. If you rename the series, rename its key in `chartConfig` as well and update `var(--color-desktop)` in `stroke` and `fill` to match. Change `type` on `Area` to switch the curve (for example `"linear"` or `"step"`), and adjust `fillOpacity` to make the fill stronger or lighter.

## Notes

`accessibilityLayer` is set on the chart, so the plot is focusable and arrow keys move the tooltip between months. `ChartContainer` turns each `chartConfig` entry into a `--color-<key>` custom property, so marks reference `var(--color-desktop)` rather than the raw token and follow light and dark appearance automatically.
