Uses `AreaChart` with one `Area` (`type="linear"`, gradient fill, `isAnimationActive={false}`), a numeric `XAxis` on `index` with custom `ticks` from `tickIndexes`, a right-hand `YAxis` padded 12% around the visible minimum and maximum, and a dashed `ReferenceLine` at the opening price. Data is generated per range by `generate()` and resampled to 80 `{ index, price, label, tick }` points. `chartConfig` is built on each render: `price` is `var(--success)` when the selected point is at or above the open and `var(--danger)` otherwise. A `ToggleGroup` switches between `1D`, `1W`, `1M`, `3M`, `1Y` and `5Y` through `React.useState`. An `ActivePoint` child reads `useActiveTooltipDataPoints` and reports the hovered index, which drives the header price, change and label. `ChartTooltip` renders `content={() => null}`, so the header replaces the floating tooltip.

Replace `generate()` and the `RANGES` table with your own data source, returning points with `index`, `price`, a `label` for the header and a `tick` for axis labels. Keep `resample()` if you want every range to have the same number of points so `useMorph` can animate between them; adjust `SAMPLES` and `MORPH_DURATION` to taste. Update the `stats` list and the symbol and name in the header for your instrument.

## Notes

`useMorph` skips the animation when `prefers-reduced-motion: reduce` matches. Pointer-capture handlers on `ChartContainer` release the cursor after a touch ends, so the header returns to the latest price on touch devices. The `ToggleGroup` has `aria-label="Time range"`, and `accessibilityLayer` keeps the plot keyboard-navigable.
