</Example>

Uses `BarChart` with one `Bar` (`dataKey="flow"`, `radius={4}`, `maxBarSize={18}`) whose children are one `Cell` per record, filled with `var(--green)` when `flow` is zero or more and `var(--red)` otherwise. A `ReferenceLine` at `y={0}` draws the baseline with `var(--separator-strong)`. `chartData` holds twelve `{ month, flow }` records, and `chartConfig` provides only a `label` for `flow`. The `XAxis` shows every other month with `interval={1}`, and the tooltip uses `hideIndicator`.

## Usage

```tsx
import { BarChartNegative } from "@/components/charts/bar-chart-negative"
```

```tsx
<BarChartNegative />
```

Replace `chartData` with signed values, keeping `month` and `flow` or renaming them in the `XAxis`, `Bar` and `Cell` logic. Change the condition or colors inside the `Cell` map to apply your own thresholds. Set `interval={0}` on `XAxis` to show every label when space allows.

## Notes

Color here is applied per `Cell` rather than through `chartConfig`, so the tooltip shows no indicator swatch. `accessibilityLayer` is set on `BarChart`, so the plot is focusable and arrow keys move between bars.
