The inner one uses `groups`, two `{ device, users, fill }` records (`phone` totaling phone and laptop, `watch` totaling tablet, watch and other), drawn at `outerRadius="52%"` with `fillOpacity={0.55}`. The outer ring uses `chartData` at `innerRadius="60%"` and `outerRadius="86%"`. Both use a 2-pixel `var(--surface-secondary)` stroke. `chartData` holds five `{ device, users, fill }` records, where each `fill` is `var(--color-<device>)`. `chartConfig` defines `users` (label only) plus `phone`, `laptop`, `tablet`, `watch` and `other` colored `var(--blue)`, `var(--teal)`, `var(--indigo)`, `var(--orange)` and `var(--gray)`. The tooltip uses `ChartTooltipContent` with `hideLabel` and `nameKey="device"`.

## Usage

```tsx
import { PieChartNested } from "@/components/charts/pie-chart-nested"
```

```tsx
<PieChartNested />
```

Replace `chartData` with your detailed categories and `groups` with their parent totals, ordering the outer ring so each group's children sit next to each other and line up with the parent slice. Give each group a `fill` and a `chartConfig` entry so its tooltip label and color resolve.

## Notes

The inner groups reuse the `phone` and `watch` keys, so their tooltip labels read Phone and Watch. Add dedicated group keys to `chartConfig` if you want distinct names. `accessibilityLayer` is set on `PieChart`, so the chart is focusable and arrow keys move between slices.
