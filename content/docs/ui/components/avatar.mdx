Avatar wraps the Base UI Avatar primitive. An `Avatar` contains an `AvatarImage` and an `AvatarFallback`; the fallback shows while the image is loading or if it fails to load. Add an `AvatarBadge` to show a status dot or icon in the bottom-end corner.

To show several people together, place avatars in an `AvatarGroup`, which overlaps them and rings each one with the surface color. End the group with an `AvatarGroupCount` to indicate how many more people there are.

## Usage

```tsx
import { Avatar, AvatarImage, AvatarFallback, AvatarBadge, AvatarGroup, AvatarGroupCount } from "@/components/ui/avatar"
```

```tsx
<Avatar>
  <AvatarImage src={people[0].src} alt={people[0].name} />
  <AvatarFallback>{people[0].initials}</AvatarFallback>
</Avatar>
```

Always provide an `AvatarFallback` alongside `AvatarImage`, usually the person's initials. The fallback can also hold an icon, which scales to 60% of the avatar.

Set `size` on each `Avatar`. Inside an `AvatarGroup`, `AvatarGroupCount` matches the size of the avatars in the group automatically.

## Accessibility

- Give `AvatarImage` an `alt` that names the person.
- `AvatarBadge` and `AvatarGroupCount` are plain elements; if they carry meaning, label them or describe the status in nearby text.

## Notes

- Styling hooks: `data-slot="avatar"`, `"avatar-image"`, `"avatar-fallback"`, `"avatar-badge"`, `"avatar-group"` and `"avatar-group-count"`, plus `data-size` on the root.
- `AvatarBadge` uses `bg-accent` by default; override it, for example with `bg-success`. At the `sm` size, icons inside the badge are hidden.
- The fallback uses a vertical gradient of `label-secondary` with `text-on-accent`.
