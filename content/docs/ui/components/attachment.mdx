An `Attachment` typically contains an `AttachmentMedia` thumbnail, an `AttachmentContent` block with `AttachmentTitle` and `AttachmentDescription`, and an `AttachmentActions` slot holding one or more `AttachmentAction` buttons. `AttachmentMedia` can hold an icon, an `img`, or an `AttachmentLabel` file-type tag. During an upload, put an `AttachmentProgress` bar inside the content. Add an `AttachmentTrigger` to make the whole card clickable.

Wrap several attachments in an `AttachmentGroup` to render them as a single list with inset dividers. Use attachments for files in composers, chat messages and upload forms.

## Usage

```tsx
import { Attachment, AttachmentLabel, AttachmentMedia, AttachmentContent, AttachmentTitle, AttachmentDescription, AttachmentProgress, AttachmentActions, AttachmentAction, AttachmentTrigger, AttachmentGroup } from "@/components/ui/attachment"
```

```tsx
<Attachment orientation="horizontal" state="done">
  <AttachmentMedia variant="document">
    <AttachmentLabel className="bg-red-600">pdf</AttachmentLabel>
  </AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>Quarterly report.pdf</AttachmentTitle>
    <AttachmentDescription>2.4 MB</AttachmentDescription>
  </AttachmentContent>
  <AttachmentActions>
    <AttachmentAction aria-label="Remove">
      <XIcon />
    </AttachmentAction>
  </AttachmentActions>
</Attachment>
```

Set `state` to reflect the file's lifecycle. `idle` adds a dashed border (outside a group), and `error` colors the description with the danger color. The `state`, `size` and `orientation` values are also exposed as `data-*` attributes for your own styling.

`AttachmentAction` renders a `Button` with the `secondary` variant and an icon size by default. Pass `variant="link"` for a text action such as "Try Again". Icon-only actions need an `aria-label`.

`AttachmentTrigger` is an invisible button stretched over the card. Give it an `aria-label`, or use `render` to turn it into a link. Actions sit above it, so they remain separately clickable.

## API Reference

### Attachment

The card container that sets size, orientation and state.

Accepts every prop of `React.ComponentProps<"div">`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"default" \| "sm" \| "xs"` | `"default"` | Overall density: `default`, `sm` or `xs`. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | `horizontal` places media beside the content; `vertical` stacks it above and overlays actions on the media. |
| `state` | `"idle" \| "uploading" \| "processing" \| "error" \| "done"` | `"done"` | Upload lifecycle state. `idle` adds a dashed border and `error` colors the description red. |

### AttachmentLabel

A small uppercase tag, usually the file extension, shown inside the media.

Accepts every prop of `React.ComponentProps<"span">`.

### AttachmentMedia

The thumbnail area for an icon, document tag or image.

Accepts every prop of `React.ComponentProps<"div">`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"icon" \| "document" \| "image"` | `"icon"` | Thumbnail style: `icon` for a bordered icon tile, `document` for a page shape with a bottom tag, `image` for a cropped image. |

### AttachmentContent

Wraps the title, description and progress bar.

Accepts every prop of `React.ComponentProps<"div">`.

### AttachmentTitle

The file name, truncated to one line.

Accepts every prop of `React.ComponentProps<"span">`.

### AttachmentDescription

Secondary details such as file size or an error message.

Accepts every prop of `React.ComponentProps<"span">`.

### AttachmentProgress

A progress bar with a value readout for uploads.

Accepts every prop of `ProgressPrimitive.Root.Props`.

### AttachmentActions

The slot for action buttons or status indicators.

Accepts every prop of `React.ComponentProps<"div">`.

### AttachmentAction

A compact button for actions such as remove, cancel or download.

Accepts every prop of `React.ComponentProps<typeof Button>`.

### AttachmentTrigger

An invisible button covering the card to make it clickable.

Accepts every prop of `useRender.ComponentProps<"button">`.

### AttachmentGroup

Stacks attachments into one rounded list with dividers.

Accepts every prop of `React.ComponentProps<"div">`.

## Accessibility

- `AttachmentProgress` wraps the Base UI Progress primitive and exposes the `progressbar` role with `aria-valuenow`; give it an `aria-label`.
- `AttachmentTrigger` renders a `button` with `type="button"` by default; give it an `aria-label` that names the file.
- The trigger and each `AttachmentAction` are separate tab stops, in that order.
- The card shows a focus ring when its trigger has keyboard focus.

## Notes

- Styling hooks: `data-slot` values such as `attachment`, `attachment-media`, `attachment-content` and `attachment-action`, plus `data-state`, `data-size` and `data-orientation` on the root and `data-variant` on the media.
- Inside `AttachmentGroup`, attachments fill the width, lose their own rounding and get inset top dividers.
- `AttachmentLabel` uses `bg-accent` by default; override it with a color class per file type.
