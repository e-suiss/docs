`Kbd` renders a single key as a native `kbd` element in a small rounded capsule. Set `mod` to prepend the platform's primary modifier: `⌘` on Apple platforms, `Ctrl` elsewhere (`Ctrl+` when the key has children).

Wrap several keys in `KbdGroup` to present a key combination. Use `Kbd` inline in text, in tooltips, or inside an input group addon to hint at a shortcut.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add kbd
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install cn
```

2. Add the pieces it builds on: `use-platform`.

3. Copy the source into `components/ui/kbd.tsx`:

<SourceCode>

```tsx title="components/ui/kbd.tsx"
"use client"

import { cn } from "cn"

import { useModifierKey } from "@/hooks/use-platform"

function Kbd({
  className,
  mod,
  children,
  ...props
}: React.ComponentProps<"kbd"> & { mod?: boolean }) {
  const modifier = useModifierKey(children != null)

  return (
    <kbd
      data-slot="kbd"
      className={cn(
        "pointer-events-none inline-flex h-5.5 max-md:hidden w-fit min-w-5.5 items-center justify-center gap-1 rounded-sm bg-surface-secondary px-1.5 font-sans text-xs text-label-secondary select-none in-data-[slot=input-group]:bg-surface in-data-[slot=tooltip-content]:bg-surface/20 in-data-[slot=tooltip-content]:text-surface dark:in-data-[slot=tooltip-content]:bg-surface/10 [&_svg:not([class*='size-'])]:size-3",
        className
      )}
      {...props}
    >
      {mod && modifier}
      {children}
    </kbd>
  )
}

function KbdGroup({ className, ...props }: React.ComponentProps<"div">) {
  return (
    <kbd
      data-slot="kbd-group"
      className={cn("inline-flex items-center gap-1 max-md:hidden", className)}
      {...props}
    />
  )
}

export { Kbd, KbdGroup }
```

</SourceCode>

4. Update the import paths to match your project.

## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

```tsx
<Kbd mod>K</Kbd>
```

Pass the key label as children. Use `mod` instead of hard-coding `⌘` or `Ctrl` so the hint matches the user's platform. Icons placed inside `Kbd` are sized to `size-3` unless they set their own `size-*` class.

## Accessibility

- Keys render as native `kbd` elements, so the text is announced as keyboard input.
- `Kbd` and `KbdGroup` are hidden below the `md` breakpoint, so do not rely on them as the only place a shortcut is documented.
- `Kbd` sets `pointer-events-none`; clicks pass through to the surrounding control, as in an input group addon.

## Notes

- Styling hooks: `data-slot="kbd"` and `data-slot="kbd-group"`.
- Platform detection reads `navigator` through `useSyncExternalStore`; during server rendering the non-Apple modifier is used.
- Inside an input group or tooltip content, `Kbd` adapts its background and text colors automatically.
- Uses the `surface-secondary`, `surface` and `label-secondary` tokens.
