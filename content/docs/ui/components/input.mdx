`Input` wraps the Base UI `Input` primitive and renders a native `input` element with a filled control style. It supports every native input `type`, including `email`, `password`, `number`, `search` and `file`, and adds a `size` prop for three heights.

Use it for short, free-form values. For multi-line text use a textarea, for icons, buttons or text attached to the field use `InputGroup`, and for one-time codes use `InputOTP`.

## Installation

2. Copy the source into `components/ui/input.tsx`:

<SourceCode>

```tsx title="components/ui/input.tsx"
import { Input as InputPrimitive } from "@base-ui/react/input"
import { cn } from "cn"
import type * as React from "react"

function Input({
  className,
  type,
  size = "default",
  ...props
}: Omit<React.ComponentProps<"input">, "size"> & {
  size?: "sm" | "md" | "default"
}) {
  return (
    <InputPrimitive
      type={type}
      data-slot="input"
      data-size={size}
      className={cn(
        "h-11 w-full min-w-0 rounded-lg border border-transparent bg-control px-3 py-1 text-base transition-[color,box-shadow,background-color] outline-none file:inline-flex file:h-7 file:border-0 file:bg-transparent file:text-sm file:text-label caret-accent placeholder:text-label-secondary focus-visible:focus-ring data-[size=md]:h-9 data-[size=md]:text-sm data-[size=sm]:h-8 data-[size=sm]:rounded-md data-[size=sm]:px-2.5 data-[size=sm]:text-sm disabled:pointer-events-none disabled:cursor-not-allowed disabled:bg-control-disabled disabled:text-label-quaternary disabled:placeholder:text-label-quaternary aria-invalid:border-danger aria-invalid:bg-danger/5 dark:aria-invalid:bg-danger/10",
        className
      )}
      {...props}
    />
  )
}

export { Input }
```

</SourceCode>

3. Update the import paths to match your project.

## Usage

```tsx
import { Input } from "@/components/ui/input"
```

```tsx
<div className="w-80">
  <Input type="text" placeholder="Enter your name" />
</div>
```

Use `defaultValue` for an uncontrolled field, or `value` with `onChange` to control it. Give every input a visible label, for example with `FieldLabel` inside a `Field`, or set `aria-label` when a visible label is not possible. Choose a `size` that matches neighboring controls such as a `Button`.

## API Reference

### Input

The text field.

Accepts every prop of `React.ComponentProps<"input">`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "default"` | `"default"` | Sets the height and text size: `default` is the tallest, `md` is medium and `sm` is the most compact with a smaller radius. |

## Accessibility

- Renders a native `input`, so the role follows its `type`: `textbox` by default, `spinbutton` for `number` and `searchbox` for `search`.
- Needs an accessible name from an associated label or `aria-label`.
- Set `aria-invalid` to communicate a validation error.
- A disabled input cannot be focused or edited.

## Notes

- Styling hooks: `data-slot="input"` and `data-size`.
- Uses the `control`, `control-disabled`, `accent` (caret), `label-secondary` (placeholder) and `danger` tokens.
- The native `size` attribute is replaced by the `size` prop.
