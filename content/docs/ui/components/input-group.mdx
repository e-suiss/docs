`InputGroup` is the container that draws the field's background, border and focus ring. Inside it, place one control, either `InputGroupInput` or `InputGroupTextarea`, and one or more `InputGroupAddon` elements. An addon can hold icons, `InputGroupText`, `InputGroupButton` or a `Kbd`, and is placed before, after, above or below the control with its `align` prop.

Use an input group when supporting content belongs inside the field, such as a search icon, a currency symbol, a clear button or a send button. For a plain field, use `Input`; for a field with a filterable list of options, use `Combobox`, which is built on this component.

## Usage

```tsx
import { InputGroup, InputGroupAddon, InputGroupButton, InputGroupText, InputGroupInput, InputGroupTextarea } from "@/components/ui/input-group"
```

```tsx
<div className="w-96">
  <InputGroup>
    <InputGroupInput placeholder="Search..." />
    <InputGroupAddon>
      <MagnifyingGlassIcon />
    </InputGroupAddon>
    <InputGroupAddon align="inline-end">12 results</InputGroupAddon>
  </InputGroup>
</div>
```

Addons are positioned with CSS order, so you can place them before or after the control in your markup. `inline-start` and `inline-end` sit beside the control; `block-start` and `block-end` sit above or below it and make the group grow to fit. Clicking an addon outside its buttons focuses the group's `input`.

`InputGroupButton` defaults to `type="button"`, so it does not submit a surrounding form unless you set `type="submit"`. Set `aria-invalid` on the control to show the error style on the whole group. To dim a disabled group's addons, disable the control and set `data-disabled="true"` on `InputGroup`.

## Examples

### Search

A search field with a clear button that appears only when there is text.

<Example kind="ui" name="input-group" story="Search">

```tsx
import { MagnifyingGlassIcon, XCircleIcon } from "@phosphor-icons/react"
import * as React from "react"
import { InputGroup, InputGroupAddon, InputGroupButton, InputGroupInput } from "@/components/ui/input-group"

function SearchField() {
  const [query, setQuery] = React.useState("MacBook")
  return (
    <InputGroup>
      <InputGroupInput
        aria-label="Search"
        placeholder="Search"
        value={query}
        onChange={(event) => setQuery(event.target.value)}
      />
      <InputGroupAddon>
        <MagnifyingGlassIcon />
      </InputGroupAddon>
      {query && (
        <InputGroupAddon align="inline-end">
          <InputGroupButton
            size="icon-xs"
            aria-label="Clear search"
            className="text-label-secondary"
            onClick={() => setQuery("")}
          >
            <XCircleIcon weight="fill" />
          </InputGroupButton>
        </InputGroupAddon>
      )}
    </InputGroup>
  )
}

export function InputGroupSearchExample() {
  return (
    <div className="w-96">
      <SearchField />
    </div>
  )
}
```

</Example>

## Accessibility

- `InputGroup` and `InputGroupAddon` have the `group` role.
- Give the control an accessible name with a label or `aria-label`; placeholder text and addon text do not name it.
- Give icon-only buttons an accessible name with `aria-label`.
- Buttons in addons are reachable with Tab after the control.
- Set `aria-invalid` on the control to communicate a validation error.

## Notes

- Styling hooks: `data-slot` values `input-group`, `input-group-addon` and `input-group-control` (on the input or textarea). Addons set `data-align`, and buttons set `data-size`.
- The group's rounded corners grow when it contains a textarea or a block addon.
- Uses the `control`, `control-disabled`, `label-secondary`, `label-quaternary` and `danger` tokens.
