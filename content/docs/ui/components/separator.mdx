`Separator` wraps the Base UI Separator primitive. It draws a 1px line in the `separator` color: full width when horizontal, and stretched to the container's height when vertical.

Use it between groups of content or between inline items. Inside menus and selects, use the dedicated separator part of that component instead.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add separator
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react cn
```

2. Copy the source into `components/ui/separator.tsx`:

<SourceCode>

```tsx title="components/ui/separator.tsx"
"use client"

import { Separator as SeparatorPrimitive } from "@base-ui/react/separator"
import { cn } from "cn"

function Separator({
  className,
  orientation = "horizontal",
  ...props
}: SeparatorPrimitive.Props) {
  return (
    <SeparatorPrimitive
      data-slot="separator"
      orientation={orientation}
      className={cn(
        "shrink-0 bg-separator data-horizontal:h-px data-horizontal:w-full data-vertical:w-px data-vertical:self-stretch",
        className
      )}
      {...props}
    />
  )
}

export { Separator }
```

</SourceCode>

3. Update the import paths to match your project.

## Usage

```tsx
import { Separator } from "@/components/ui/separator"
```

```tsx
<div className="w-72">
  <div className="flex flex-col gap-1">
    <h4 className="text-sm font-medium">Account settings</h4>
    <p className="text-label-secondary text-sm">
      Manage your profile and preferences.
    </p>
  </div>
  <Separator orientation="horizontal" className="my-4" />
  <div className="flex h-5 items-center gap-4 text-sm">
    <span>Profile</span>
    <Separator orientation="vertical" />
    <span>Billing</span>
    <Separator orientation="vertical" />
    <span>Security</span>
  </div>
</div>
```

`orientation` defaults to `horizontal`. Set `orientation="vertical"` inside a flex row; the line stretches to the row's height, so give the row a height.

## API Reference

### Separator

Draws the dividing line.

Accepts every prop of `SeparatorPrimitive.Props`.

## Accessibility

- Renders with the `separator` role and an `aria-orientation` that matches `orientation`.

## Notes

- Uses `data-slot="separator"` and Base UI's `data-horizontal` and `data-vertical` attributes for sizing.
- The color comes from the `bg-separator` token.
