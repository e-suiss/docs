Drawer wraps the Base UI Drawer. The `Drawer` root manages the open state and the swipe direction, and `DrawerTrigger` opens it. `DrawerContent` renders the panel in a portal, over a dimmed `DrawerOverlay` when modal, with an optional swipe handle and close button. Inside it, `DrawerHeader` holds the `DrawerTitle` and `DrawerDescription`, and `DrawerFooter` holds the actions. `DrawerClose` closes the drawer from any element.

The drawer opens from the bottom by default and can also open from the top, left or right. It supports snap points, a floating style inset from the screen edges, and a non-modal mode. To get the iOS sheet effect, where the page behind scales down as a bottom drawer opens, wrap the page in `DrawerProvider` with `DrawerIndentBackground` and `DrawerIndent`. Use a drawer for touch-friendly, swipeable panels; for a centered window, use a dialog.

"use client"

import { Drawer as DrawerPrimitive } from "@base-ui/react/drawer"
import { XIcon } from "@phosphor-icons/react"
import { cn } from "cn"
import * as React from "react"
import { Button } from "@/components/ui/button"

type DrawerContextProps = {
  floating: boolean
  hasSnapPoints: boolean
  modal: DrawerPrimitive.Root.Props["modal"]
  showSwipeHandle: boolean
  swipeDirection: NonNullable<DrawerPrimitive.Root.Props["swipeDirection"]>
}

const DrawerContext = React.createContext<DrawerContextProps | null>(null)

type DrawerIndentContextProps = {
  raised: boolean
  setRaised: (raised: boolean) => void
}

const DrawerIndentContext =
  React.createContext<DrawerIndentContextProps | null>(null)

function useDrawer() {
  const context = React.useContext(DrawerContext)

  if (!context) {
    throw new Error("useDrawer must be used within a Drawer.")
  }

  return context
}

function DrawerProvider({ children }: DrawerPrimitive.Provider.Props) {
  const [raised, setRaised] = React.useState(false)
  const contextValue = React.useMemo(() => ({ raised, setRaised }), [raised])

  return (
    <DrawerIndentContext.Provider value={contextValue}>
      <DrawerPrimitive.Provider>{children}</DrawerPrimitive.Provider>
    </DrawerIndentContext.Provider>
  )
}

function DrawerIndentBackground({
  className,
  ...props
}: DrawerPrimitive.IndentBackground.Props) {
  return (
    <DrawerPrimitive.IndentBackground
      data-slot="drawer-indent-background"
      className={cn("fixed inset-0 -z-10 bg-label dark:bg-surface", className)}
      {...props}
    />
  )
}

function DrawerIndent({ className, ...props }: DrawerPrimitive.Indent.Props) {
  const indent = React.useContext(DrawerIndentContext)

  return (

      data-slot="drawer-indent"

}

function Drawer({
  floating = false,
  modal = true,
  showSwipeHandle = false,
  snapPoints,
  swipeDirection = "down",
  open: openProp,
  defaultOpen = false,
  onOpenChange,
  snapPoint: snapPointProp,
  defaultSnapPoint,
  onSnapPointChange,
  ...props
}: DrawerPrimitive.Root.Props & {
  floating?: boolean
  showSwipeHandle?: boolean
}) {
  const hasSnapPoints = snapPoints != null && snapPoints.length > 0
  const indent = React.useContext(DrawerIndentContext)
  const setRaised = indent?.setRaised
  const initialSnapPoint = defaultSnapPoint ?? snapPoints?.[0] ?? null
  const [uncontrolledOpen, setUncontrolledOpen] = React.useState(defaultOpen)
  const [uncontrolledSnapPoint, setUncontrolledSnapPoint] =
    React.useState(initialSnapPoint)
  const open = openProp ?? uncontrolledOpen
  const snapPoint =
    snapPointProp !== undefined ? snapPointProp : uncontrolledSnapPoint
  const raised =
    open &&
    !floating &&
    swipeDirection === "down" &&
    (!hasSnapPoints || snapPoint === snapPoints.at(-1))

  React.useEffect(() => {
    if (!setRaised) return
    setRaised(raised)
    return () => setRaised(false)
  }, [setRaised, raised])

  const contextValue = React.useMemo(
    () => ({ floating, hasSnapPoints, modal, showSwipeHandle, swipeDirection }),
    [floating, hasSnapPoints, modal, showSwipeHandle, swipeDirection]
  )

  return (
    <DrawerContext.Provider value={contextValue}>
      <DrawerPrimitive.Root
        data-slot="drawer"
        modal={modal}
        snapPoints={snapPoints}
        swipeDirection={swipeDirection}
        open={openProp}
        defaultOpen={defaultOpen}
        onOpenChange={(next, eventDetails) => {
          setUncontrolledOpen(next)
          if (next) setUncontrolledSnapPoint(initialSnapPoint)
          onOpenChange?.(next, eventDetails)
        }}
        snapPoint={snapPointProp}
        defaultSnapPoint={defaultSnapPoint}
        onSnapPointChange={(next, eventDetails) => {
          setUncontrolledSnapPoint(next)
          onSnapPointChange?.(next, eventDetails)
        }}
        {...props}
      />
    </DrawerContext.Provider>
  )
}

The drawer is uncontrolled by default; set `defaultOpen` to start open, or control it with `open` and `onOpenChange`. Set `swipeDirection` to `down`, `up`, `left` or `right` to choose the edge it opens from and the direction it is swiped to close.

Pass `snapPoints`, such as `[0.5, 1]`, to let people drag the drawer between heights; it opens at the first snap point unless you set `defaultSnapPoint`, or control it with `snapPoint` and `onSnapPointChange`. Set `modal={false}` to keep the rest of the page interactive; no overlay is rendered in that case.

For the indented page effect, place `DrawerIndentBackground` and `DrawerIndent` inside `DrawerProvider` and put the page content in `DrawerIndent`. The page is scaled while a non-floating drawer that opens from the bottom is open, and, with snap points, only at the last snap point.

## API Reference

### DrawerProvider

Coordinates drawers with `DrawerIndent` so the page can react when a drawer opens.

Accepts every prop of `DrawerPrimitive.Provider.Props`.

### DrawerIndentBackground

The dark layer shown behind the page when it scales down.

Accepts every prop of `DrawerPrimitive.IndentBackground.Props`.

### DrawerIndent

Wraps the page content and scales it down while a bottom drawer is open.

Accepts every prop of `DrawerPrimitive.Indent.Props`.

### Drawer

The root that manages the open state, swipe direction and snap points.

Accepts every prop of `DrawerPrimitive.Root.Props`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `floating` | `boolean` | `false` | Insets the drawer from the screen edges and rounds all of its corners. |
| `showSwipeHandle` | `boolean` | `false` | Shows a grab bar on the edge of the panel that faces the screen center. |

### DrawerTrigger

The button that opens the drawer.

Accepts every prop of `DrawerPrimitive.Trigger.Props`.

### DrawerPortal

Renders its children into a portal outside the current DOM hierarchy.

Accepts every prop of `DrawerPrimitive.Portal.Props`.

### DrawerClose

A button that closes the drawer.

Accepts every prop of `DrawerPrimitive.Close.Props`.

### DrawerOverlay

The dimmed layer behind a modal drawer, which fades as the drawer is swiped away.

Accepts every prop of `DrawerPrimitive.Backdrop.Props`.

### DrawerSwipeHandle

The grab bar people drag to move or dismiss the drawer.

Accepts every prop of `React.ComponentProps<"div">`.

### DrawerContent

The drawer panel, rendered in a portal with an optional overlay, swipe handle and close button.

Accepts every prop of `DrawerPrimitive.Popup.Props`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showCloseButton` | `boolean` | `false` | Shows a close button in the top corner. |
| `closeLabel` | `string` | — | Replaces the close button's icon with this text. |

### DrawerHeader

Groups the title and description.

Accepts every prop of `React.ComponentProps<"div">`.

### DrawerFooter

Holds the drawer's actions at the bottom of the panel.

Accepts every prop of `React.ComponentProps<"div">`.

### DrawerTitle

The drawer's title, which also names it for assistive technology.

Accepts every prop of `DrawerPrimitive.Title.Props`.

### DrawerDescription

Supporting text that describes the drawer for assistive technology.

Accepts every prop of `DrawerPrimitive.Description.Props`.

## Accessibility

- The panel has the `dialog` role. `DrawerTitle` provides its accessible name and `DrawerDescription` its accessible description.
- Opening the drawer moves focus inside it. Escape closes it and returns focus to the trigger.
- A non-modal drawer does not set `aria-modal`.
- The swipe handle is hidden from assistive technology, so always provide another way to close the drawer, such as a `DrawerClose` button.
- The icon-only close button has a visually hidden `Close` label.

## Notes

- Styling hooks: `data-slot` values such as `drawer-popup`, `drawer-content`, `drawer-overlay`, `drawer-swipe-handle`, `drawer-close-button`, `drawer-header`, `drawer-footer` and `drawer-indent`.
- The panel sets `data-swipe-direction`, `data-swipe-axis`, and, when applicable, `data-floating` and `data-snap-points`. A drawer at its last snap point gets `data-expanded`. `DrawerIndent` gets `data-raised` while the page is scaled.
- Side drawers are `75%` wide, and `24rem` wide from the `sm` breakpoint. Top and bottom drawers are limited to the viewport height minus `6rem`.
- Nested drawers stack, with the drawer behind scaled down slightly.
- Uses the `surface-raised`, `scrim`, `surface` and `label-quaternary` tokens. Animations are disabled on `DrawerIndent` when reduced motion is preferred.
