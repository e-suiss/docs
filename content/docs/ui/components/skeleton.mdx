`Skeleton` is a plain `div` with a pulsing animation, rounded corners and a `surface-secondary` fill. It has no size of its own; set width, height and shape with utility classes so each placeholder matches the content it replaces.

Combine several skeletons to sketch a layout, such as an avatar with two lines of text. For an indeterminate activity indicator, use `Spinner` instead.

## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add skeleton
```

### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install cn
```

2. Copy the source into `components/ui/skeleton.tsx`:

<SourceCode>

```tsx title="components/ui/skeleton.tsx"
import { cn } from "cn"

function Skeleton({ className, ...props }: React.ComponentProps<"div">) {
  return (
    <div
      data-slot="skeleton"
      className={cn("animate-pulse rounded-md bg-surface-secondary", className)}
      {...props}
    />
  )
}

export { Skeleton }
```

</SourceCode>

3. Update the import paths to match your project.

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"
```

```tsx
<Skeleton className="h-4 w-48" />
```

Size every skeleton with classes such as `h-4 w-48`. Use `rounded-full` for avatars and other rounded shapes to override the default `rounded-md`.

## Accessibility

- `Skeleton` renders an empty `div` with no role or text, so it isn't announced. Let assistive technologies know content is loading another way, for example with `aria-busy` on the region that's loading.

## Notes

- Uses `data-slot="skeleton"`, the `animate-pulse` animation and the `bg-surface-secondary` token.
