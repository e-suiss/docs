`Spinner` is an SVG of eight fading spokes that rotates in steps, like the system activity indicator. It draws in `currentColor` and is `size-4` by default, so it inherits the surrounding text color.

Use it for short waits whose length is unknown, such as saving or loading more. For a placeholder that previews the shape of content, use `Skeleton`.

## Installation


### Manual

1. Install the dependencies:

```bash title="Terminal"
npm install cn
```

2. Copy the source into `components/ui/spinner.tsx`:

<SourceCode>

```tsx title="components/ui/spinner.tsx"
import { cn } from "cn"

const spokes = Array.from({ length: 8 }, (_, index) => ({
  angle: index * 45,
  opacity: Number((0.2 + (0.8 * index) / 7).toFixed(2)),
}))

function Spinner({ className, ...props }: React.ComponentProps<"svg">) {
  return (
    <svg
      data-slot="spinner"
      role="status"
      aria-label="Loading"
      viewBox="0 0 24 24"
      fill="currentColor"
      className={cn(
        "size-4 shrink-0 animate-[spin_0.8s_steps(8)_infinite]",
        className
      )}
      {...props}
    >
      {spokes.map(({ angle, opacity }) => (
        <rect
          key={angle}
          x="10.44"
          y="0.5"
          width="3.12"
          height="7.2"
          rx="1.56"
          opacity={opacity}
          transform={`rotate(${angle} 12 12)`}
        />
      ))}
    </svg>
  )
}

export { Spinner }
```

</SourceCode>

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner"
```

```tsx
<Spinner />
```

Change the size with a `size-*` class and the color with a `text-*` class. Inside a `Button`, pair it with `disabled` and give it `data-icon="inline-start"` to place it before the label.

## API Reference

### Spinner

The animated activity indicator.

Accepts every prop of `React.ComponentProps<"svg">`.

## Accessibility

- Renders with the `status` role and the accessible name `Loading`. Override `aria-label` to describe the specific task.

## Notes

- Uses `data-slot="spinner"`.
- The rotation lasts `0.8s` and moves in eight steps, so one spoke advances at a time.
