## Installation

### CLI

```bash title="Terminal"
npx @esuiss/ui@latest add button
```

`init` also adds the button, so a project set up with `init` already has it.

### Manual

Install the dependencies:

```bash title="Terminal"
npm install @base-ui/react class-variance-authority cn
```

Then copy the source of `components/ui/button.tsx` from the [suiss UI repository](https://github.com/e-suiss/ui/blob/main/components/ui/button.tsx) into `components/ui/button.tsx` in your project.

## Usage

```tsx
import { Button } from "@/components/ui/button"
```

```tsx
<Button>Continue</Button>
```

### Block

`block` makes the button fill the width of its container. Block buttons use a rounded rectangle instead of a pill, scaled to their size.

<Preview>
  <Button block>Add to Bag</Button>
</Preview>

```tsx
<Button block>Add to Bag</Button>
```

### With an icon

Mark an icon with `data-icon="inline-start"` or `data-icon="inline-end"` so the button tightens its padding on that side. Icons without a size class are sized automatically.

```tsx
import { ArrowRightIcon, PlusIcon } from "@phosphor-icons/react"

<Button>
  <PlusIcon data-icon="inline-start" />
  New project
</Button>
<Button variant="outline">
  Continue
  <ArrowRightIcon data-icon="inline-end" />
</Button>
```

## API Reference

`Button` accepts every prop of the Base UI `Button`, plus the props below.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "tinted" \| "ghost" \| "plain" \| "destructive" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-xl"` | `"default"` |
| `block` | `boolean` | — |
| `className` | `string` | — |

The file also exports `buttonVariants`, the class-variance-authority function behind these props, so you can apply button styles to other elements.
