        </SelectGroup>
      </SelectContent>
    </Select>
  )

`Select` wraps the Base UI Select primitive. `SelectTrigger` shows the current choice through `SelectValue` and a chevron icon; `SelectContent` renders the popup in a portal, positioned against the trigger, and holds `SelectItem` options. Use `SelectGroup` with a `SelectLabel` to title a set of options, and `SelectSeparator` to divide groups.

A highlight pill slides between options as the highlighted item changes, and the selected item shows a check mark. Use `Select` when people choose one value from a fixed list. For a few always-visible options, consider `ToggleGroup` or `RadioGroup`.

function trackHighlight(list: HTMLDivElement | null) {
  const indicator = list?.querySelector<HTMLElement>(
    "[data-slot=select-highlight]"
  )
  if (!list || !indicator) return
  const update = () => {
    const item = list.querySelector<HTMLElement>(
      "[data-slot=select-item][data-highlighted]"
    )
    if (!item) {
      delete indicator.dataset.visible
      return
    }
    const instant = !("visible" in indicator.dataset)
    if (instant) indicator.dataset.instant = ""
    indicator.style.top = `${item.offsetTop}px`
    indicator.style.left = `${item.offsetLeft}px`
    indicator.style.width = `${item.offsetWidth}px`

    indicator.dataset.visible = ""
    if (instant) {
      void indicator.offsetHeight
      delete indicator.dataset.instant

## Usage

```tsx
import { SelectGroup, SelectValue, SelectTrigger, SelectContent, SelectLabel, SelectItem, SelectSeparator, SelectScrollUpButton, SelectScrollDownButton } from "@/components/ui/select"
```

```tsx
<Select items={fruits}>
  <SelectTrigger aria-label="Fruit" className="w-48">
    <SelectValue placeholder="Select a fruit" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      {fruits.map((fruit) => (
        <SelectItem key={fruit.value} value={fruit.value}>
          {fruit.label}
        </SelectItem>
      ))}
    </SelectGroup>
  </SelectContent>
</Select>
```

Pass `items` to `Select` as `{ value, label }` pairs so `SelectValue` can show the label for the chosen value, even before the popup opens. Use `defaultValue` for an uncontrolled select, or `value` with `onValueChange` to control it. `SelectValue` shows its `placeholder` until a value is chosen.

`SelectContent` opens below the trigger by default. It accepts the positioner props `side`, `sideOffset`, `align`, `alignOffset` and `alignItemWithTrigger`.

      { value: "est", label: "Eastern Time" },
      { value: "cst", label: "Central Time" },
      { value: "pst", label: "Pacific Time" },

  },
  {
    label: "Europe",
    items: [
      { value: "gmt", label: "Greenwich Mean Time" },
      { value: "cet", label: "Central European Time" },
      { value: "eet", label: "Eastern European Time" },
    ],
  },

  return (
    <Select items={timezones.flatMap((group) => group.items)} defaultValue="cet">

          <Fragment key={group.label}>
            {index > 0 && <SelectSeparator />}
            <SelectGroup>
              <SelectLabel>{group.label}</SelectLabel>
              {group.items.map((item) => (
                <SelectItem key={item.value} value={item.value}>
                  {item.label}
                </SelectItem>
              ))}
            </SelectGroup>
          </Fragment>
        ))}
      </SelectContent>

## API Reference

### SelectGroup

Groups related options; label it with a `SelectLabel`.

Accepts every prop of `SelectPrimitive.Group.Props`.

### SelectValue

Shows the selected option's label, or the placeholder, inside the trigger.

Accepts every prop of `SelectPrimitive.Value.Props`.

### SelectTrigger

The button that opens the popup and displays the current value.

Accepts every prop of `SelectPrimitive.Trigger.Props`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "default"` | `"default"` | Sets the trigger height: `default` is 44px tall, `sm` is 36px with smaller corners. |

### SelectContent

The positioned popup that holds the option list and scroll arrows.

Accepts every prop of `SelectPrimitive.Popup.Props` and `SelectPrimitive.Positioner.Props`.

### SelectLabel

A heading that names a `SelectGroup`.

Accepts every prop of `SelectPrimitive.GroupLabel.Props`.

### SelectItem

A selectable option, with a check mark when selected.

Accepts every prop of `SelectPrimitive.Item.Props`.

### SelectSeparator

A thin line that divides groups of options.

Accepts every prop of `SelectPrimitive.Separator.Props`.

### SelectScrollUpButton

An arrow that scrolls the list up when it overflows; rendered by `SelectContent`.

Accepts every prop of `React.ComponentProps<typeof SelectPrimitive.ScrollUpArrow>`.

### SelectScrollDownButton

An arrow that scrolls the list down when it overflows; rendered by `SelectContent`.

Accepts every prop of `React.ComponentProps<typeof SelectPrimitive.ScrollDownArrow>`.

## Accessibility

- The trigger has the `combobox` role and the popup list has the `listbox` role; each item is an `option` with `aria-selected` on the chosen one.
- Give the trigger an accessible name, such as `aria-label` or an associated label.
- When the popup opens, focus moves to the selected option. Arrow keys move between options and `Enter` selects.
- `Escape` closes the popup without changing the value, and focus returns to the trigger.
- A `SelectGroup` with a `SelectLabel` is exposed as a named `group`.

## Notes

- Parts carry `data-slot` attributes such as `select-trigger`, `select-content`, `select-item` and `select-highlight`.
- The trigger sets `data-size`, and styles `data-placeholder`, `aria-invalid` and `disabled` states. Invalid triggers use the `danger` color.
- The popup uses `bg-surface-raised`, the highlight uses `bg-item-hover`, and the check mark uses `text-link`.
- The highlight animation is turned off when reduced motion is preferred.
