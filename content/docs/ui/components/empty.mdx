`Empty` is a centered container for empty states. Inside it, `EmptyHeader` groups an optional `EmptyMedia` with an `EmptyTitle` and `EmptyDescription`, and `EmptyContent` holds the actions, such as buttons, a search field or a help link. All parts are plain, styled elements with no interactive behavior of their own.

Use it when a list, folder, search or page has nothing to show. Keep the title short and use the description to suggest a next step.

import { cn } from "cn"

function Empty({ className, ...props }: React.ComponentProps<"div">) {
  return (
    <div
      data-slot="empty"
      className={cn(
        "flex w-full min-w-0 flex-1 flex-col items-center justify-center gap-4 rounded-2xl border-dashed p-12 text-center text-balance",
        className
      )}
      {...props}
    />
  )

function EmptyHeader({ className, ...props }: React.ComponentProps<"div">) {
  return (
    <div
      data-slot="empty-header"
      className={cn("flex max-w-sm flex-col items-center gap-2", className)}
      {...props}
    />
  )
}

const emptyMediaVariants = cva(
  "mb-2 flex shrink-0 items-center justify-center [&_svg]:pointer-events-none [&_svg]:shrink-0",
  {
    variants: {
      variant: {
        default: "bg-transparent",
        icon: "flex size-10 shrink-0 items-center justify-center rounded-lg bg-surface-secondary text-label [&_svg:not([class*='size-'])]:size-5",

    defaultVariants: {
      variant: "default",
    },
  }

  className,
  variant = "default",
  ...props

  return (
    <div
      data-slot="empty-icon"
      data-variant={variant}
      className={cn(emptyMediaVariants({ variant, className }))}
      {...props}
    />
  )
}

      data-slot="empty-description"
      className={cn(

        className
      )}
      {...props}
    />

## Usage

```tsx
import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent } from "@/components/ui/empty"
```

```tsx
<div className="w-[32rem]">
  <Empty>
    <EmptyHeader>
      <EmptyMedia variant="icon">
        <FolderSimpleIcon />
      </EmptyMedia>
      <EmptyTitle>No projects yet</EmptyTitle>
      <EmptyDescription>
        You haven&apos;t created any projects yet. Get started by creating
        your first project.
      </EmptyDescription>
    </EmptyHeader>
    <EmptyContent>
      <div className="flex gap-2">
        <Button>Create project</Button>
        <Button variant="outline">Import project</Button>
      </div>
      <Button variant="link" size="sm" className="text-label-secondary">
        Learn more
        <ArrowUpRightIcon data-icon="inline-end" />
      </Button>
    </EmptyContent>
  </Empty>
</div>
```

`Empty` has a dashed border style but no border width by default; add `border` through `className` to show an outline. Set `EmptyMedia` to `variant="icon"` for a small icon in a tinted tile, or keep the default to render media such as a large icon or illustration as is. Links placed directly inside `EmptyDescription` are underlined.

## API Reference

### Empty

The centered container for the empty state.

Accepts every prop of `React.ComponentProps<"div">`.

### EmptyHeader

Groups the media, title and description.

Accepts every prop of `React.ComponentProps<"div">`.

### EmptyMedia

Holds an icon or image above the title.

Accepts every prop of `React.ComponentProps<"div">`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "icon"` | `"default"` | `icon` places the icon in a small rounded tile with a secondary surface; `default` renders the media without a background. |

### EmptyTitle

The short heading of the empty state.

Accepts every prop of `React.ComponentProps<"div">`.

### EmptyDescription

Supporting text that explains the state or suggests a next step.

Accepts every prop of `React.ComponentProps<"p">`.

### EmptyContent

Holds actions such as buttons, inputs or links.

Accepts every prop of `React.ComponentProps<"div">`.

## Accessibility

- `EmptyTitle` renders a `div`, not a heading. If the empty state should appear in the document outline, render a heading element inside it or pass the appropriate role and level.
- Give interactive elements in `EmptyContent` clear accessible names.

## Notes

- Styling hooks: `data-slot` values `empty`, `empty-header`, `empty-icon` (on `EmptyMedia`), `empty-title`, `empty-description` and `empty-content`.
- `EmptyMedia` also sets `data-variant`.
- `EmptyDescription` renders a `div` element even though it accepts paragraph props.
- Uses the `surface-secondary`, `label`, `label-secondary` and `link` tokens.
