A `ButtonGroup` lays out its children in a row or column and joins them visually: only the outer corners stay rounded, and borders between neighbors collapse. Use `ButtonGroupSeparator` to draw a divider between filled buttons, and `ButtonGroupText` to add a static label or prefix such as `https://`.

Groups can contain buttons, `Input`, `InputGroup`, `Select` triggers, and the triggers of dropdown menus and popovers. Nest `ButtonGroup` parts to create clusters with a gap between them. Use a button group for closely related actions, split buttons, or input-and-button combinations; for a set of toggleable options, use Toggle Group instead.

import { useRender } from "@base-ui/react/use-render"
import { cva, type VariantProps } from "class-variance-authority"
import { cn } from "cn"

import { Separator } from "@/components/ui/separator"

const buttonGroupVariants = cva(
  "flex w-fit items-stretch *:data-slot:bg-clip-border [&>[data-variant=ghost]]:rounded-full! [&>[data-variant=plain]]:rounded-full! *:[--focus-ring-offset:-3px] *:focus-visible:relative *:focus-visible:z-10 has-[>[data-slot=button-group]]:gap-2 has-[>[data-variant=outline]]:*:data-[slot=input-group]:border-separator has-[>[data-variant=outline]]:*:data-[slot=select-trigger]:border-separator [&>[data-slot=select-trigger]:not([class*='w-'])]:w-fit [&>input]:flex-1 has-[>[data-variant=outline]]:[&>input]:border-separator",
  {
    variants: {
      orientation: {
        horizontal:
          "*:data-slot:rounded-e-none [&>[data-slot]:first-child]:rounded-s-full [&>[data-slot]:not(:has(~[data-slot]))]:rounded-e-full! [&>[data-slot]~[data-slot]]:rounded-s-none [&>[data-slot]~[data-slot]]:border-s-0",
        vertical:
          "flex-col *:data-slot:rounded-b-none [&>[data-slot]:first-child]:rounded-t-2xl [&>[data-slot]:not(:has(~[data-slot]))]:rounded-b-2xl! [&>[data-slot]~[data-slot]]:rounded-t-none [&>[data-slot]~[data-slot]]:border-t-0",
      },
    },
    defaultVariants: {
      orientation: "horizontal",
    },
  }
)

function ButtonGroup({
  className,
  orientation,
  ...props
}: React.ComponentProps<"div"> & VariantProps<typeof buttonGroupVariants>) {
  return (
    <div
      role="group"
      data-slot="button-group"
      data-orientation={orientation}
      className={cn(buttonGroupVariants({ orientation }), className)}
      {...props}
    />
  )
}

function ButtonGroupText({
  className,
  render,
  ...props
}: useRender.ComponentProps<"div">) {
  return useRender({
    defaultTagName: "div",
    props: mergeProps<"div">(
      {
        className: cn(
          "flex items-center gap-2 rounded-full bg-control px-2.5 text-sm [&_svg]:pointer-events-none [&_svg:not([class*='size-'])]:size-4",
          className
        ),
      },
      props
    ),
    render,
    state: {
      slot: "button-group-text",
    },
  })
}

function ButtonGroupSeparator({
  className,
  orientation = "vertical",
  ...props
}: React.ComponentProps<typeof Separator>) {
  return (
    <Separator
      data-slot="button-group-separator"
      orientation={orientation}
      className={cn(
        "relative z-10 bg-label/20 data-horizontal:mx-2.25 data-horizontal:-mb-px data-horizontal:w-auto data-vertical:my-2.25 data-vertical:-me-px data-vertical:h-auto",
        className
      )}
      {...props}
    />
  )
}

export { ButtonGroup, ButtonGroupSeparator, ButtonGroupText }

Elements are joined only when they expose a `data-slot` attribute, as the library's components do.

When a group contains other `ButtonGroup` parts, the outer group adds a gap between them instead of joining them.

`ButtonGroupSeparator` is vertical by default. In a vertical group, pass `orientation="horizontal"`. Separators are most useful between `secondary` or `default` buttons; `outline` buttons already show their borders.

Give the group an `aria-label` when its purpose is not clear from its contents, as in the pagination and media control examples.

## API Reference

### ButtonGroup

The container that joins its children and sets the orientation.

Accepts every prop of `React.ComponentProps<"div">`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction of the group. `horizontal` joins items in a row with pill ends; `vertical` stacks them with rounded top and bottom. |

### ButtonGroupText

A static, button-shaped label for text or icons.

Accepts every prop of `useRender.ComponentProps<"div">`.

### ButtonGroupSeparator

A thin divider between adjacent items.

Accepts every prop of `React.ComponentProps<typeof Separator>`.

## Accessibility

- `ButtonGroup` renders with `role="group"`; add an `aria-label` to name it.
- Each button, input and trigger remains a separate tab stop in document order.
- Icon-only buttons inside a group need an `aria-label`.
- `ButtonGroupText` renders a `div` and is not focusable; use `render` to render a `label` element if it labels an input.

## Notes

- Styling hooks: `data-slot="button-group"`, `"button-group-text"` and `"button-group-separator"`, plus `data-orientation` on the group.
- Focused items are raised with `z-10` so their focus ring is not clipped by neighbors.
- In groups containing `outline` buttons, inputs, input groups and select triggers also get the `border-separator` color.
