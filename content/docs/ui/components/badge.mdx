`Badge` is a single element that renders a `span` by default. Use the `render` prop to render it as another element, such as a link. Badges can hold text and an icon on either side.

Use a badge to tag content with a short status or category. For actions, use Button instead.

2. Copy the source into `components/ui/badge.tsx`:

<SourceCode>

```tsx title="components/ui/badge.tsx"
import { mergeProps } from "@base-ui/react/merge-props"
import { useRender } from "@base-ui/react/use-render"
import { cva, type VariantProps } from "class-variance-authority"
import { cn } from "cn"

const badgeVariants = cva(
  "inline-flex h-5 w-fit shrink-0 items-center justify-center gap-1 overflow-hidden rounded-full border border-transparent text-xs font-semibold whitespace-nowrap transition-colors focus-visible:focus-ring aria-invalid:border-danger [&>svg]:pointer-events-none [&>svg]:size-3!",
  {
    variants: {
      variant: {
        default: "text-link [a]:hover:underline",
        secondary: "text-label-secondary [a]:hover:underline",
        destructive:
          "text-danger [--focus-ring-color:var(--color-danger)] [a]:hover:underline",
        outline:
          "border-separator px-2 text-label has-data-[icon=inline-end]:pe-1.5 has-data-[icon=inline-start]:ps-1.5 [a]:hover:bg-item-hover",
        ghost:
          "px-2 has-data-[icon=inline-end]:pe-1.5 has-data-[icon=inline-start]:ps-1.5 [a]:hover:bg-item-hover [a]:hover:text-label-secondary",
        link: "text-link hover:underline",
      },
    },
    defaultVariants: {
      variant: "default",
    },
  }
)

function Badge({
  className,
  variant = "default",
  render,
  ...props
}: useRender.ComponentProps<"span"> & VariantProps<typeof badgeVariants>) {
  return useRender({
    defaultTagName: "span",
    props: mergeProps<"span">(
      {
        className: cn(badgeVariants({ variant }), className),
      },
      props
    ),
    render,
    state: {
      slot: "badge",
      variant,
    },
  })
}

export { Badge }
```

</SourceCode>

3. Update the import paths to match your project.

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
```

```tsx
<Badge>Badge</Badge>
```

Mark icons with `data-icon="inline-start"` or `data-icon="inline-end"` so the `outline` and `ghost` variants tighten their padding on that side. Icons are sized to `size-3`.

Pass `render` with an anchor element, for example an `a` with an `href`, to make the badge a link. Linked badges get hover styles that depend on the variant.

To use a custom color, override the text color with a `className` such as `text-success`.

## Accessibility

- A badge is static text by default and is not focusable.
- When rendered as a link, it shows a focus ring on keyboard focus.
- `aria-invalid` adds a danger-colored border.

## Notes

- Styling hook: `data-slot="badge"`, plus `data-variant` from the render state.
- The `destructive` variant also sets the focus ring color to `--color-danger`.
- Badges are a fixed `h-5` with fully rounded corners and do not wrap text.
