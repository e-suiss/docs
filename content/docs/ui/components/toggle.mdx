`Toggle` wraps the Base UI Toggle primitive. When pressed, it shows a tinted background and `link`-colored content, and it scales down slightly while being pressed.

Use a toggle for a single on-off option such as bold text or a bookmark. To choose among related options, use `ToggleGroup`; for a setting that takes effect immediately, use `Switch`.

        outline: "border border-separator bg-transparent hover:bg-item-hover",
      },
      size: {
        default:
          "h-9 min-w-9 px-3 has-data-[icon=inline-end]:pe-2.5 has-data-[icon=inline-start]:ps-2.5",
        sm: "h-8 min-w-8 px-3 has-data-[icon=inline-end]:pe-2 has-data-[icon=inline-start]:ps-2",
        lg: "h-10 min-w-10 px-4 has-data-[icon=inline-end]:pe-3 has-data-[icon=inline-start]:ps-3",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "default",
    },
  }
)

function Toggle({
  className,
  variant,
  size,
  ...props
}: TogglePrimitive.Props & VariantProps<typeof toggleVariants>) {
  return (
    <TogglePrimitive
      data-slot="toggle"
      className={cn(toggleVariants({ variant, size, className }))}
      {...props}
    />
  )
}

export { Toggle, toggleVariants }

## Usage

```tsx
import { Toggle } from "@/components/ui/toggle"
```

```tsx
<Toggle aria-label="Toggle bold"><TextBIcon /></Toggle>
```

Use `defaultPressed` for an uncontrolled toggle, or `pressed` with `onPressedChange` to control it. Mark an icon beside a label with `data-icon="inline-start"` or `data-icon="inline-end"` to tighten the padding on that side.

## API Reference

### Toggle

The pressable two-state button.

Accepts every prop of `TogglePrimitive.Props`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "outline"` | `"default"` | Uses a borderless `default` style or an `outline` style with a border. |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` | Sets the height and padding: `sm`, `default` or `lg`. |

## Accessibility

- Renders a `button` with `aria-pressed` reflecting its state.
- `Enter` and `Space` toggle the focused button.
- An icon-only toggle needs an `aria-label`.

## Notes

- Uses `data-slot="toggle"`. Pressed styles key off `aria-pressed`.
- `toggleVariants` is exported so other components, such as `ToggleGroupItem`, can share the styles.
- The press animation is removed when reduced motion is preferred.
