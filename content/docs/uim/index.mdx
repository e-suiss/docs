## Overview

suiss UIM brings suiss components to React Native and Expo projects with TypeScript. Components cover common controls and overlays: buttons, dialogs, dropdown menus, popovers, selects, tabs, tooltips and more.

The components reach your project through the `@esuiss/uim` command-line tool. The tool copies each component's source into your project.

```bash title="Terminal"
npx @esuiss/uim@latest init
npx @esuiss/uim@latest add dialog
```

## Principles

### You own the code

Components live in your repository, under `components/ui/`. Change them however you like. Updates never replace your files unless you ask: review the difference with `--diff`, then replace with `--overwrite`.

### Uniwind or NativeWind

Components are styled with Tailwind CSS v4 class names through one of two libraries:

| Library | Works with |
| --- | --- |
| Uniwind | Expo, and React Native without Expo |
| NativeWind v5 | Expo only. NativeWind v5 is a release candidate and needs Expo's Metro config |

The styling library is detected from your project. When neither is installed, `init` asks.

### Native-aware setup

In Expo projects, packages are installed with `expo install`, so native modules match your Expo SDK. In React Native projects without Expo, the CLI also configures Babel for the `@/*` alias and adds the Reanimated Babel plugin when a component needs it.

### The Apple system colors

The theme uses the Apple system colors, with a light and a dark value for each token. See [Theming](/docs/uim/theming).

### Phosphor icons

Icons come from `phosphor-react-native`, rendered through the `icon` component.
