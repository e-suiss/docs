## Installation

### CLI

```bash title="Terminal"
npx @esuiss/uim@latest add button
```

`init` also adds the button, so a project set up with `init` already has it.

### Manual

The button depends on the `text` component. Install the dependencies of both:

```bash title="Terminal"
npx expo install class-variance-authority cn @rn-primitives/slot
```

In React Native projects without Expo, install the same packages with your package manager.

Then copy the source files from the [suiss UIM repository](https://github.com/e-suiss/uim) into your project:

| File | Uniwind source | NativeWind source |
| --- | --- | --- |
| `components/ui/text.tsx` | `components/ui/text.tsx` | `components/ui/text.tsx` |
| `components/ui/button.tsx` | `components/ui/button.tsx` | `nativewind/components/ui/button.tsx` |

## Usage

```tsx
import { Button } from "@/components/ui/button"
import { Text } from "@/components/ui/text"
```

```tsx
<Button>
  <Text>Continue</Text>
</Button>
```

Put the label in a `Text`. The button passes its text styles to `Text` children, so the label matches the variant and size.

### Icon

Icon sizes make a square button. Render the icon with the `icon` component and a Phosphor icon.

```tsx
import { PlusIcon } from "phosphor-react-native"
import { Icon } from "@/components/ui/icon"

<Button size="icon" variant="outline">
  <Icon as={PlusIcon} />
</Button>
```

### Icon extra small

### Disabled

A disabled button is drawn at 50% opacity.

```tsx
<Button disabled>
  <Text>Disabled</Text>
</Button>
```

## API Reference

`Button` accepts every prop of React Native `Pressable`, plus the props below.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `disabled` | `boolean` | — |
| `className` | `string` | — |

The file also exports `ButtonProps`, `buttonVariants` and `buttonTextVariants`, the class-variance-authority functions behind the button and its label.
