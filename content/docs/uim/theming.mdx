## How the theme works

`init` writes the theme to `global.css`. Its contents depend on the styling library.

- **Uniwind.** Colors are defined in `@layer theme`, with one set under `@variant light` and one under `@variant dark`. The radius scale is in an `@theme` block.
- **NativeWind v5.** Colors and the radius scale are in an `@theme` block, with dark values under `@media (prefers-color-scheme: dark)`.

Each color is a Tailwind color, so `--color-primary` gives you `bg-primary`, `text-primary`, `border-primary` and so on.

```css title="global.css (Uniwind)"
@import "tailwindcss";
@import "uniwind";

@layer theme {
  :root {
    @variant light {
      --color-background: #ffffff;
      --color-foreground: #000000;
      --color-primary: #0088ff;
    }

    @variant dark {
      --color-background: #000000;
      --color-foreground: #ffffff;
      --color-primary: #0091ff;
    }
  }
}
```

## Using tokens

```tsx
<View className="rounded-lg border border-border bg-card p-4">
  <Text className="text-card-foreground">Title</Text>
  <Text className="text-muted-foreground">Supporting text</Text>
</View>
```

Tokens come in pairs. A background token such as `primary` has a matching `-foreground` token for the text on it.

## Opacity with NativeWind

NativeWind v5 can't apply opacity modifiers such as `bg-destructive/10` to theme colors that change with dark mode. The NativeWind stylesheet and components use precomputed tokens instead:

| Uniwind class | NativeWind class |
| --- | --- |
| `bg-destructive/10` | `bg-destructive-10` |
| `bg-primary/80` | `bg-primary-80` |
| `bg-muted/50` | `bg-muted-50` |

When you choose NativeWind, `add` copies the NativeWind version of each component, so you get these classes automatically.

## Customize

- **Change a color.** Edit its light and dark values in `global.css`.
- **Add a color.** Define a `--color-*` variable with a light and a dark value. Its classes, such as `bg-brand` for `--color-brand`, become available.
- **Change the radius.** Edit the `--radius-*` values.
